App Information

  • Name: RepoPress Studio
  • Platform: macOS 14 or later
  • Category: Developer Tools
  • Site generators: Zola, Hugo, Astro, Jekyll, and Hexo
  • Account: local features require no RepoPress Studio account
  • Privacy: no advertising, behavioral tracking, or third-party analytics SDK

Current App Store Edition

Every user can configure a local model or an OpenAI-compatible HTTPS API and use AI chat, rewriting, summaries, metadata, and review assistance. AI does not require RepoPress Pro. The app does not meter AI requests, sell AI credits or provider access, or link to provider purchases.

Before the first remote AI request, the app shows the destination and possible data categories and requires explicit consent. API keys stay in macOS Keychain, and requests travel directly from this Mac to the provider selected by the user; the developer does not receive keys, prompts, or responses.

Full-text and semantic indexes are generated locally. Browser captures enter the app on the same device only through the authenticated 127.0.0.1:17843 loopback connection and are not sent to the developer's servers.

Main Features

  • Markdown editing, live preview, structured metadata, images, and general drafts.
  • A local library for EPUB, PDF, Markdown, TXT, HTML, and web content selected by the user.
  • Custom AI APIs, AI chat, writing assistance, and content review for every user, with no app-defined request quota.
  • Content-health, SEO, social-preview, link, image, taxonomy, and maintenance checks.
  • Local change and remote-difference review, followed by user-confirmed GitHub or GitLab sync and publishing.
  • User-initiated browser capture through the embedded Safari Web Extension.
  • Quick Hide and masking for articles marked private.

Frequently Asked Questions

Do reviewers or users need a demo account or API key?

Local writing, research, and repository features need no account or API key. Remote AI requires a key for the user's own provider account; an unauthenticated loopback model needs no key. RepoPress Studio does not sell or purchase provider access.

Why does the app request folder access?

The App Store edition uses App Sandbox. It accesses only repositories, research sources, and output locations selected through system panels and restores previously granted access with security-scoped bookmarks.

How do I reopen the main window?

Choose Window > Show RepoPress Studio, or press Command-0.

When does the app use the network?

Network access is limited to user-configured and initiated AI requests, GitHub/GitLab actions, repository remotes, deployment checks, StoreKit purchase or restore, browser-extension installation, and pages you choose to open. Remote AI also requires endpoint-specific explicit consent. The app does not upload drafts or library content automatically.

Does Quick Hide encrypt files?

No. Quick Hide and private-content masking reduce on-screen exposure. They are not password or Touch ID authentication, disk encryption, or end-to-end encryption.
