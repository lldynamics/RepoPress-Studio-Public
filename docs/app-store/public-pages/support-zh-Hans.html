RepoPress Studio · 技术支持

RepoPress Studio 是面向 Git 驱动静态站点作者的本地优先工作台，集中处理 Markdown 写作、本地资料整理、内容检查、浏览器网页采集、仓库同步和部署状态。

应用信息

  • 名称：RepoPress Studio
  • 平台：macOS 14 或更高版本
  • 类别：开发者工具
  • 支持站点：Zola、Hugo、Astro、Jekyll 和 Hexo
  • 账号：本地功能不要求注册 RepoPress Studio 账号
  • 隐私：不包含广告、行为跟踪或第三方分析 SDK

当前 App Store 版本

所有用户都可以配置自己的本地模型或 OpenAI 兼容 HTTPS API，并使用 AI 对话、改写、摘要、元数据和检查辅助。AI 不要求购买 RepoPress Pro，应用不限制 AI 请求次数、不销售 AI 额度或服务商访问权限，也不提供购买服务商账户的链接。

远程 AI 请求首次发送前会显示目标地址和可能发送的数据并要求明确同意。API Key 保存在 macOS 钥匙串，请求由此 Mac 直接发送到用户选择的服务商；开发者不会收到 Key、提示词或回复。

资料库中的全文和语义索引都在本机生成。浏览器采集仅通过带随机配对令牌的 127.0.0.1:17843 回环连接进入同一台设备上的应用，不会发送到开发者服务器。

主要功能

  • Markdown 编辑、实时预览、元数据、图片和通用草稿管理。
  • 导入 EPUB、PDF、Markdown、TXT、HTML 和网页内容，建立本地资料库。
  • 面向所有用户开放自定义 AI API、AI 对话、写作辅助和内容检查，不计应用内使用次数。
  • 内容健康、SEO、社交预览、链接、图片、分类和维护检查。
  • 查看本地变更和远端差异，并在用户确认后执行 GitHub/GitLab 同步或发布。
  • 使用内置 Safari Web Extension 采集用户主动选择的网页。
  • 快速隐藏工作区，并遮挡标记为私密的文章信息。

常见问题

需要演示账号或 API Key 吗？

本地写作、资料库和仓库功能不需要账号或 API Key。使用远程 AI 时，用户需要填写自己服务商账户的 API Key；使用不要求认证的本机回环模型时不需要 Key。RepoPress Studio 不出售或代购服务商访问权限。

为什么需要文件夹权限？

App Store 版本使用 App Sandbox，只访问你通过系统面板选择的仓库、资料和输出位置，并通过安全书签恢复你已经授予的访问权。

关闭主窗口后如何重新打开？

在菜单栏选择“窗口 > 显示 RepoPress Studio”，或按 Command-0。

什么时候会访问网络？

只有用户配置并触发的 AI 请求、GitHub/GitLab 操作、仓库远端同步、部署状态检查、StoreKit 购买或恢复、浏览器扩展安装，以及主动打开的网页会访问对应服务。远程 AI 请求还要求按端点明确同意。应用不会自动上传草稿或资料库内容。

快速隐藏是否等于文件加密？

不是。快速隐藏和私密内容遮挡只减少屏幕暴露，不提供密码、Touch ID、磁盘加密或端到端加密。
