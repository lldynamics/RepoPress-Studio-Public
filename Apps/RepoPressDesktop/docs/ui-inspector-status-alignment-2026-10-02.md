# 工作台 UI 对齐：第二批

日期：2026-10-02。承接[第一批](ui-workbench-alignment-2026-10-02.md)，继续使用第一批固定的 macOS 参考。本批实现独立文章检查器和统一窗口状态栏，保留现有数据、发布及恢复流程。

## 已实现

- 打开文章时默认显示属性检查器。Front Matter 编辑从正文上方移到“属性 · SEO”，继续修改编辑缓冲区，保存动作沿用原流程。SEO 报告中的字段定位会展开正确字段并保持属性输入焦点，不自动创建属性。
- “诊断 · 查找”承载本地 Markdown 诊断、查找替换、章节与图片信息。两个标签页保持挂载；关闭检查器或进入专注模式时隐藏稳定区域，保留查找条件、SEO 报告及正文实例。跨文档或文档 revision 变化按既有文档键重置检查器；正文修改使旧 SEO 报告失效。
- 检查器按工作台实际宽度布局：容器至少 1280px 时，最右侧保留 320px，再为原三栏分配空间；较窄时进入独立下方区域并允许工作区纵向滚动，不覆盖正文或预览。显式打开、切换标签、Ctrl/Cmd-F、点击状态诊断时滚入可见范围；默认打开不会自动跳到底部。
- 底部统一显示保存状态、只读标记、文稿路径、光标/行跳转、字词与字符统计、预计阅读时间、编码、当前缓冲区换行格式及本地诊断数量。统计和诊断复用已有规则，同一摘要同时供状态栏与检查器使用。
- 无文稿不宣称“已保存”或“零问题”；只读演示不宣称保存成功，仍保留 dirty/saving/conflict/failed 的真实状态。后端小写格式规范显示为 UTF-8、LF、CRLF 等，未知格式原样保留。
- 标签支持方向键、Home/End 和正确 tab/tabpanel 关联。只有保存状态设 live region，字数和光标变化不会导致整栏不断播报。
- 检查器遵循批量操作、冲突审阅及安全退出门控；非模态检查器不再阻止安全退出请求。本批没有新增 Gateway 或 Rust 调用。

## 并行分工与工作树

主线程负责 App 接线、属性迁移、焦点、状态摘要、集成测试和浏览器验收。Sol high 独占布局与检查器组件；Luna medium 独占状态栏；Sol xhigh 只读独立复核。运行时未提供 Terra，沿用第一批 Sol high 分工。

保存了本批开始时 2231 个源文件的哈希与相关原文件，最终没有缺失基线文件。其他线程并行修改的发布恢复模块、Vite 配置和其文档已保留，本批不归因、不覆盖这些改动。没有提交、推送、合并、重置或清理工作树。

## 验收

当前集成工作区完整前端验证：122 个测试文件、776 项测试全部通过。TypeScript 与 Vite 生产构建通过；包体预算通过，启动 JavaScript 为 542.7 KiB，9 个懒加载块。`git diff --check` 通过。

```sh
npm test -- --run
npm run build
npm run check:bundle
git diff --check
```

- 独立复核没有阻断发现。最终滚动可见性小增量复核运行 App navigation 与 editor exit，共 2 文件、22 项通过。
- 集成测试覆盖属性字段焦点、报告失效/跨文档重置、标签切换/关闭/专注模式保活、实时缓冲区统计和诊断入口、默认检查器打开时的安全退出。既有批量操作和导航锁测试继续通过。
- 真实浏览器演示验证 1440×900、940×800、375×812 及明暗主题，使用内置只读样例，不执行真实保存、发布或构建站点。
- 1440×900 时文件导航 250px、正文 422px、预览 340px、检查器 320px，页面宽度保持 1440px。浏览器发现并修复 docked 检查器的 Grid 自动放置问题；DOM 测试仅验证规则与挂载，不替代实际几何证据。
- 940×800 和 375×812 时检查器为下方区域。点击诊断后其 220px 区域滚入可见范围，底部与固定状态栏相接；页面宽度分别保持 940px 和 375px，检查器内容可独立滚动。
- 浏览器确认键盘切换标签，关闭/再打开后查找条件保留。
