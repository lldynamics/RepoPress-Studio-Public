# P36：单个冻结提交的逆向变更预览

发布中心的 Git 推送记录新增“预览单提交逆向变更”。明确点击后，读取冻结提交与其唯一父提交，展示逆向删除、恢复、替换及两端对象信息。预览只读、只用本地对象，不查询远端或凭据，也不执行回滚。

## 已实现范围

- 沿用 P35 的本地基础条件：从 P31 私有台账按会话仓库、记录 ID 和精确版本读取，要求推送已核实、回执远端 SHA 与冻结 SHA 一致，复核仓库/common-dir 身份和唯一有效推送 URL。根提交、合并提交、替换引用、来源/父提交或根树对象缺失及不可核验、目标漂移和未核实记录均明确阻塞；变化文件 blob 缺失则显示部分结果。
- 读取真实的原始 commit/tree/blob 字节，按 Git 的类型、字节数和内容重新计算 SHA-1 或 SHA-256；读取前先检查对象类型与大小。核验来源提交、父提交、两份根树、变化路径经过的子树及必要的普通文件对象。相同 mode/OID 的项跳过；未逐一核验未变化文件对象。
- 冻结提交独有的普通文件显示逆向“删除”，父提交独有的显示“恢复”，两端均存在的显示“替换”，包含执行位变化。重命名明确拆成删除和恢复，不推断 rename/copy。二进制文件同样核验原始字节；IPC 只返回路径、模式、对象 ID、字节数和问题，不返回正文或补丁。
- 符号链接、gitlink 和文件/目录类型转换显示不支持；不跟随链接，不读取链接目标或子模块仓库。类型转换的目录内容不展开，其行不能当作完整文件清单。
- UTF-8 路径按组件检查，拒绝穿越、`.git`、控制字符、非便携分隔符/保留字符、尾随点或空格、设备保留名及超过 4096 字节的路径。危险名称不回显；可确定的叶项省略数量累加，无法展开的子树/超限范围显示省略数量未知。
- 最多 200 行、512 个不同树对象、32 层子目录，单对象最多 64 KiB，合计对象读取最多 4 MiB。对象读取与差异遍历共享 20 秒预算；其前后的台账/基础条件复验另受既有 Git 命令超时约束。Git 禁用替换、按需下载和全部传输协议，不调用外部 diff、textconv 或过滤器。
- 结果区分完整、部分和阻塞：完整只表示本次边界内变化路径所需对象均已核验，没有警告或遗漏；缺失、过大、哈希不符、特殊类型或达到预算时明确显示问题和部分结果。不能读取或核验两端提交/根树时阻塞，失败不会冒充完整的零变更结果；两份根树经核验确实相同时，可以返回完整的空清单。摘要只计算已展示行。
- 返回前重新读取完整台账记录，并比较初始父提交与本地阻塞条件；包括检查过程中从阻塞恢复的变化，也要求重新预览。命令返回前再次比较会话仓库。界面校验身份、方向、对象模式、摘要和状态矩阵；台账刷新、会话/版本/目标变化、禁用、卸载或网关变化会清除旧结果，迟到响应不能回填。每页展示 50 行。

## 保留边界与下一步

预览针对一个冻结提交相对唯一父提交，不代表整次多提交推送。完整预览不证明未变化文件对象都可用、全站/附件可恢复、revert 无冲突、当前远端一致、写入权限或部署成功。对象读取与最终复验不是跨文件系统原子快照，之后 GC 或外部修改仍可能使证据失效；未来执行必须重新验证。

本批没有文件正文 diff、回滚命令导出、本地/远端执行、PR/MR 撤回、合并提交 mainline、对象备份或完整恢复事务。P35 候选取消后的内存槽位仍按五分钟过期清理。真实 GitHub/GitLab、真实凭据/故障、原生窗口和 Linux 桌面矩阵未验收，也没有打包或发布发行产物。

下一批建议 P37：在独立临时 Git 环境中生成本地逆向提交候选，核验目标树与来源关系，提供绑定证据的短时审阅计划。先补齐候选完整性、特殊类型拒绝、失败清理和用户工作区保留；远端写入、执行前远端复验和持久恢复事务继续单独设计。

同日后续：[P37 本地逆向提交候选](p37-local-rollback-candidate.md)已补齐完整的有界目标树核验、一次性计划与临时构建/读回/清理。P36 原批次验证及变化对象边界保留；P37 也不执行远端回滚或备份整条提交历史。
