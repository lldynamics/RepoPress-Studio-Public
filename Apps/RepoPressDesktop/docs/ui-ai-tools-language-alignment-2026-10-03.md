# 工作台 UI 对齐：第七批

日期：2026-10-03。承接[第六批恢复与影响审阅](ui-recovery-impact-language-alignment-2026-10-03.md)，沿用[第一批](ui-workbench-alignment-2026-10-02.md)固定的 macOS 参考。本批完成智能工具入口、AI 选区编辑、模型发现与连接测试、AI 对话、PDF/OCR 和离线语义检索的简中/English 界面迁移。没有刷新 macOS 比较基线，不宣称最新实机像素一致。

## 已实现

- 智能工具的标题、说明、标签、ARIA 与关闭按钮支持双语；标签键盘导航、选中面板和焦点逻辑保持原有行为。
- AI 选区编辑的配置、凭据状态、发送计划、提案逐项接受、编辑器缓冲区应用和错误提示支持双语。初次挂载时，默认编辑指令按当前语言初始化；之后语言切换不替换指令或用户输入。
- 模型发现和连接测试的受控状态、warning code、计划、有效期、确认、过滤和结果说明支持双语。模型名、端点与请求参数保持原值；沿用已有连接错误遮蔽规则，不直接显示未识别的运输错误或 warning 详情。
- AI 对话的服务配置、会话、资料选择、发送计划、流式状态、取消、加密历史和口令说明支持双语；日期、大小与受控枚举按语言显示。浏览器演示明确显示“当前环境不提供加密历史”，不再显示无法完成的读取等待。
- PDF/OCR 的能力检查、文件选择、文字层提取、本地 OCR、结果、复制和资料导入控件支持双语。已知 warning code 在展示时翻译，未知 warning 保留原文。
- 离线语义检索的索引状态、重建、查询、结果数量、截断说明和定位控件支持双语。英文模板使用完整句子和英文标点。
- 本批使用已有语义颜色变量，限定在 `.advanced-tools` 内修正 warning/error/ready/danger 的深浅色表现和英文换行；内容区、子区块和动作按钮保留可用的滚动宽度。

## 行为与数据边界

语言仅参与展示。切换语言不重新读取能力、索引、凭据或历史，不创建新请求，不延长计划有效期，不重置输入、模型过滤、OCR 语言、许可勾选、冻结计划、选区、提案接受状态和搜索结果。原有 Gateway/config/session 身份校验、generation 过期响应保护、单次确认、取消和流式轮询继续生效。

本地延迟 notice/error 通过 `UiMessage` 保存来源和参数，渲染时翻译；本地“未知错误” fallback 与文字相同的后端错误分别处理。原始错误遵循现有路径遮蔽、换行清理和长度限制。原始数据中的模板字样只插值一次，不被再次解析。

保存的服务配置、会话标题、模型名、URL、路径、文件名、正文、搜索片段、reason、后端 summary 和未知 warning 保持原文。新会话的原有数据标题“新对话”没有因界面迁移而被改写。已生成的指令、计划、提案和消息内容不随语言切换重写。

本批没有增加 Gateway 方法、网络路径、Rust 命令或真实写入权限。浏览器演示继续禁用真实凭据访问、AI 发送、资料读取、PDF 文件选择和提取；测试通过隔离 Gateway 桩验证丰富状态，没有执行真实模型请求、历史解锁、剪贴板写入、PDF 读取、资料导入或索引重建。

## 分工与工作树保护

主线程负责智能工具入口、AI 编辑和连接组件、共享字典接线、样例历史状态、主题与换行、整合及最终验收。Sol high 独占 AI 对话组件、词典和测试；Luna medium 独占文档与语义检索组件、词典和测试，完成后顺序补充生命周期测试；Sol xhigh 独立只读复核并运行最终集成 gate。运行时没有 Terra，判断较多的有界实现使用 Sol high。子代理没有继续委派，写代理文件范围没有重叠。

开工保存 2308 个源文件哈希及 12 个关键文件副本；最终基线缺失文件为 0。同期资料引用完整性、备份设置、README、契约、Gateway、Rust 和比较文档的变化保留，不归因为本批实现。其开发过程中的 TypeScript 诊断随后在并行模块修正，本批没有改动那些文件。`App.tsx`、`App.navigation.test.ts`、两个 AI 独立 CSS 文件及 `aiConnectionPresentation.ts` 相对开工基线未变。没有提交、推送、合并、重置或清理工作树。
