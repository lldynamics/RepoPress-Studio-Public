# 工作台 UI 对齐：第五批

日期：2026-10-03。承接[第四批写作工具与诊断](ui-writing-tools-language-alignment-2026-10-02.md)，沿用[第一批](ui-workbench-alignment-2026-10-02.md)固定的 macOS 参考。本批完成发布中心主面板、执行记录、推送重试、当前文稿检查及只读 Git diff 的简中/English 文案迁移，并统一发布提示在浅色/深色主题中的颜色。

## 已实现

- 发布中心标题、关闭控件、桌面集成、Git 能力状态、Commit/Fetch/Push 计划、暂存区选择、凭据表单、PR/MR 表单、AppImage 更新候选和部署初始提示支持双语。
- 本地发布结果记录、远端审查记录、核实计划、记录删除确认以及推送重试计划支持双语。已核实、未核实、远端不同、未匹配和结果不明确的解释保持原有语义。
- 当前文稿的本地 Markdown 检查复用内置诊断展示描述；标题、建议、行号和定位按钮支持双语。生成报告时保存的原文和范围仍用于定位，文稿改变后报告仍失效。
- Git 状态、受控 warning 枚举、diff 状态及 ARIA 标签支持双语。工作树与暂存区补丁、分支、状态代码和文件路径直接显示原文；未知 warning 和错误不按界面字典猜测含义。
- 成功、警告、错误和危险操作采用工作台主题色。发布抽屉和计划内容允许长文案换行，英文按钮在窄屏换行。

## 行为与数据边界

语言只参与展示，不进入发布数据加载、报告失效、异步请求或计划执行的依赖。语言往返保留同一提交说明、凭据输入、PR/MR 标题和正文、暂存路径选择、已生成计划及进行中的请求，不增加 Gateway 调用。

计划有效期的展示随界面语言变化，过期判断继续使用既有 helper。session/generation、冻结 planId、单次执行、缺少推送地址、核实 evidence/revision 和只读 capability 保护保持有效。语言切换本身不会执行、重新生成或延长计划。

只有受控的本地 UI 模板和标签进入翻译。后端 summary、warning、更新说明、原始错误，以及 URL、路径、SHA、Host、分支、标题和正文保持原文。本地部署初始提示与真正后端观察通过现有 observation 状态区分，不依据文字或 checkedAt 推断来源。因此英文界面仍可能显示中文后端消息。

发布中心原有绝对路径脱敏规则保持不变，并在保存通知状态前执行。本地生成的 `[本地文件]` 占位和未知错误 fallback 可随语言变化；后端恰好返回相同文字时仍按字面显示。参数只插值一次，后端或用户数据中的模板字样不会被再次解释。令牌不进入通知、翻译参数或日志；保存凭据后清空令牌的行为保持不变。

## 分工与工作树保护

主线程负责发布中心与计划卡片、结构化通知、共享字典接线、主题颜色、App 集成测试、浏览器验收和最终整合。Sol high 独占发布/审查记录与推送重试组件及对应字典/测试；Luna medium 独占当前文稿检查与 Git 状态组件及对应字典/测试；Sol xhigh 独立只读复核。子代理没有继续委派。运行时没有 Terra，判断较多的有界包沿用 Sol high。

开工保存 2276 个源文件哈希及关键文件副本；最终基线缺失文件为 0。并行变化的 WorkspaceConfigBackupPanel、其测试、README 和 macOS/Linux 比较文档保留且不归因为本批实现。先前 dirty 工作树的 Rust、契约、Gateway、备份和 macOS 修改均保留。没有提交、推送、合并、重置或清理工作树。
