# 工作台 UI 对齐：第一批

日期：2026-10-02。macOS 参考固定为本地 `origin/main@2d2858f`；Linux 对照包含现有未提交工作区。本批聚焦主导航、工作台空间分配和工具栏，不代表完整 macOS UI 或原生窗口验收。

## 已实现

- 增加“写作、资料库、RSS 阅读、图片工作台、同步”主导航。当前选中项由实际打开的表面派生；顶栏和命令面板打开相同表面时导航同步更新。资料、图片和同步继续复用已有面板和发布确认流程。
- 顶栏保留选择仓库、新建、保存、发布和命令搜索；Git 刷新及主题切换进入“更多操作”。智能工具、通用草稿、操作日志和设置移到导航辅助区。
- 宽窗侧栏与预览支持拖动和键盘调宽；方向键每次 10px，Home/End 到边界。布局限制为正文保留至少 360px。面板隐藏和断点变化保留宽度偏好，且不重新挂载编辑器。
- 按工作台的实际容器宽度响应：900px 起横向三栏；600–899px 为侧栏、正文与下方预览；600px 以下文件导航默认收拢为“仓库文件”，展开后限高滚动，正文和预览纵向排列。
- `repopress.workspace.layout.v1` 仅保存两个数字宽度。非法值归一化；存储不可用时继续使用内存布局，不保存路径、文章或凭据。
- Markdown 高频操作直达，溢出格式归入“插入”和“格式”；密度、自定义和快捷键帮助归入“工具栏选项”。保留原有显式空偏好、隐藏命令和格式动作。
- 行编辑、表格、中文排版、图片、站内链接、片段和导出归入“写作工具”。菜单关闭不卸载内容，不丢弃进行中的操作；Escape 返回菜单触发点，格式执行保留应用回调安排的编辑器焦点。
- 导航继承批量修改执行锁与安全退出冻结；这次没有修改 Gateway、数据协议或 Rust 后端。

## 并行分工

- 主线程：导航、顶栏、App 接线、菜单布局、最终集成和浏览器验收。
- Luna medium：Markdown 工具栏及聚焦测试。
- Sol high：布局组件和布局策略；本次运行时未提供 Terra。
- Sol xhigh：只读独立复核与最终聚焦验证。

每个写入工作包独占文件。现有未提交工作保留，没有提交、推送、合并、重置或清理工作树。

## 验证

最终验证结果：118 个测试文件、749 项前端测试全通过；TypeScript、Vite 生产构建和包体预算通过。启动 JavaScript 为 536.9 KiB，检测到 9 个懒加载块。

- 前端完整 Vitest、TypeScript 和 Vite 生产构建。
- 生产包体预算及 `git diff --check`。
- 独立复核覆盖导航唯一选中、批量修改/退出锁、编辑器挂载稳定性、拖动取消与菜单焦点。
- 浏览器演示验证 1440×900、940×800、375×812，明暗主题、键盘调宽、导航收拢与展开、菜单显示范围。使用内置只读示例，不执行真实保存、发布或站点构建。
- 浏览器实测发现并修正窄窗侧栏压缩及紧凑布局菜单裁剪问题；jsdom 的 DOM 测试不作为 CSS 实际尺寸证据。
- 375×812 下导航收起行高 38px、展开行高 220px，页面宽度保持 375px；940×800 下写作菜单底部位于工作区可见范围内。重载浏览器后已确认调宽结果保留。
