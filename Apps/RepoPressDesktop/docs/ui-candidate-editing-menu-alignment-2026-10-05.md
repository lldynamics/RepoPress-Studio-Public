# 工作台 UI 对齐：第十一批

日期：2026-10-05。承接[第十批资料包、弹窗与站点管理](ui-package-dialog-site-alignment-2026-10-03.md)，继续沿用既有固定 macOS 参考。本批补齐资料候选副本、候选检查和三个编辑菜单的简中/English 呈现。没有刷新 macOS 比较基线，不宣称最新实机像素一致。

## 已实现

- `KnowledgePackageStagePanel` 的操作、说明、状态、明文确认、计划与结果摘要、受控错误和 ARIA 支持双语。数量、字节和日期使用当前语言；来源、父目录、候选路径及 SHA 原值保留。
- `KnowledgeCandidateCheckPanel` 的选择、检查、重新核对、取消、报告、当前资料库状态和元数据冲突摘要支持双语。未知数量继续显示未知；原始候选路径和 SHA 使用单次参数插值。
- `MarkdownAdvancedEditingMenu` 与 `MarkdownTableEditingMenu` 的菜单、命令标签、提示和完成反馈支持双语；`MarkdownDocumentExportMenu` 的格式、不可用说明、忙碌状态和 ARIA 支持双语，成功、取消和错误回调保持原有流程。
- 三个菜单增加最大宽度和长标签换行；导出操作组允许换行。现有明暗颜色、悬停、焦点、禁用、定位和层级规则保持不变。此项有源码审查，当前没有浏览器布局测量证据。

## 行为与数据边界

语言没有加入选择、检查、重新核对或其他 effect 的依赖。切换语言不会重发请求、重置候选路径或明文确认、延长五分钟有效期、改变丢弃规则或恢复一次性权限。原有校验、generation、来源/上下文绑定、忙碌锁、计划消费及 Gateway 调用保持不变。

候选检查保持原有数据范围：不增加正文、资料标题、来源 URL 或基线未展示字段，不把缺失的当前资料库数量呈现为零。原始参数中的中文和 `{candidatePath}` 等内容保持字面值。未知后台错误仍采用原有受控提示，不暴露私有错误详情。

编辑命令 ID、辅助函数、选区、禁用条件、空结果处理和菜单关闭行为保持不变。导出仍由原有 `createMarkdownDocumentExportPlan` 单次创建并捕获计划；`onSave`、`onSuccess` 和 `onError` 使用同一个计划对象，取消保持静默且不触发成功或错误回调。这里的捕获不表示使用 `Object.freeze`。语言切换只更新显示。主窗口原有导出结果 notice 未纳入本批迁移。

本批没有修改 Rust、契约、Gateway、`App.tsx`、`App.css` 或全局 i18n 接线。三个新词典由对应组件引入，没有加入全局词典列表。同期 P50 恢复资格功能由另一条任务实施，其源码和文档全部保留，不纳入本批实现或 Rust 验收。

## 分工与工作树保护

主线程负责候选检查、共享词典门禁、菜单布局、整合和最终验收。Sol high 独占候选副本组件及测试；Luna medium 独占三个菜单及测试；Sol xhigh 执行独立只读审查与最终全量前端测试。运行时没有 Terra，判断较多的有界实现使用 Sol high。写入范围不重叠，没有子代理继续委派。

开工保存 2386 个文件哈希及关键源文件副本。本批共 15 个源码/测试文件（8 个已有、7 个新增），另新增本篇记录并更新第十批覆盖矩阵。限定源码的组合 diff 为 862 行。最终收口补强了导出计划严格对象身份、空编辑结果和菜单开关状态的测试；修正了新测试的 mock 参数类型。最终基线没有文件缺失，15 个源码文件与冻结哈希全部匹配；另有 10 个已有、8 个新增并发文件被完整保留。共享 App、全局 i18n 和两个旧候选组件测试相对开工未变。没有提交、推送、合并、重置、清理或改写历史。
