# 工作台 UI 对齐：第十批

日期：2026-10-03。承接[第九批 RSS 翻译与备份](ui-rss-translation-backup-alignment-2026-10-03.md)，继续沿用既有固定 macOS 参考。本批补齐已保存资料 JSON 包检查、草稿新建/移动/重命名/删除、退出以及站点管理的简中/English 呈现，修正深色弹窗和长文本布局。没有刷新 macOS 比较基线，不宣称最新实机像素一致。

## 已实现

- `KnowledgePackageCheckPanel` 的说明、操作、状态、报告、固定排除项和一次性内存预检结果支持双语。数量、字节和日期按当前语言显示；来源路径和 SHA 原值保留。
- `DraftLifecycleDialog` 的三个操作模式、提示、路径标签、占位符、忙碌状态和按钮支持双语。未知错误仍按原文显示。
- `EditorExitDialog` 的恢复说明、错误、导出结果和退出方式支持双语。控制器生成的本地错误增加可选展示来源；已有调用方若没有展示来源，仍按原始错误显示。恢复包路径保留 `<code>` 语义与原值。
- `SiteProfileCenter` 的读取、登记、重命名、打开、移除确认和本地延迟反馈支持双语。受控错误代码与原始后台错误分别呈现，站点名、路径和后台警告不进入词典。
- 原生退出 `<dialog>` 是主窗口的兄弟节点，本批补齐其本地明暗主题变量，让按钮、边框和警告使用正确颜色。草稿弹窗增加高度限制、纵向滚动和按钮换行；站点管理补齐长字段换行与最小宽度约束。

## 行为与数据边界

语言没有加入读取、检查、请求、焦点或退出 effect 的依赖。切换语言不会重发请求、重开原生弹窗、重置已编辑路径/名称、清除确认、改变原有有效期或重新获得一次性预检权限。插值只执行一次，原始参数中的 `{path}`、`{name}`、`{sha256}` 保持字面内容。

资料包的 schema、枚举、精确字段、SHA、来源、上下文、generation、忙碌锁、丢弃规则、五分钟 TTL 和单次预检行为相对开工保持不变。完整明文、固定排除、逐文件校验与可恢复性说明仍显示；没有增加正文、标题或来源 URL 等基线未展示字段。

草稿路径仍由既有规则约束。站点移除仍绑定冻结的 profile 与 revision；移除登记保留仓库和草稿。退出仍使用原快照、prepare/complete 流程，成功后保持 busy 和编辑冻结，等待原生退出；失败时才允许返回编辑。控制器原有通用失败提示仍隐藏未知私有错误，没有扩大退出或导出权限。

本批没有修改 Rust、契约、Gateway、`App.tsx`、`App.css` 或全局 i18n 接线。三个新词典由对应组件引入，没有加入全局词典列表；退出/草稿组件本来就在启动路径上，构建预算仍通过。

## 分工与工作树保护

主线程负责站点管理、共享退出错误展示来源、词典门禁、主题/布局、整合和最终验收。Sol high 独占资料包检查；Luna medium 独占草稿/退出组件和对应测试；Sol xhigh 执行独立只读审查和一次最终全量测试。运行时没有 Terra，判断较多的有界实现使用 Sol high。写入范围不重叠，没有子代理继续委派。

开工保存 2359 个文件哈希及关键源文件副本，本批共 15 个源码/测试文件（7 个已有、8 个新增），另新增本篇记录并更新第九批覆盖矩阵。同期资料候选副本功能的 8 个已有、8 个新增文件涉及 Rust、契约、Gateway 和设置组件，全部保留，不纳入本批 UI 实现或 Rust 验收。开工基线没有文件缺失。

限定源码的组合 diff 为 1011 行。收口审查发现导出路径 `<code>` 语义丢失、测试原生弹窗 descriptor 清理不完整，以及词典共享译文冲突，均在最终冻结前修复。没有提交、推送、合并、重置、清理或改写历史。视觉测试只移除本批自行创建的两个临时入口，副本保留在 `/tmp`。
