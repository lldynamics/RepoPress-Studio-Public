# P43：RSS 单库一致性快照备份

2026-10-03，继续固定 macOS 比较基线 `2d2858fc5ebc3843d1a281026304c2551741691c`，Linux HEAD `97f1fd75e12b4b9606974890bfa317a7bac9b6e3`。本批没有 fetch/合并/提交/推送，保留已有本地与并行 UI 改动。

## 实现范围

设置中心新增“RSS 数据库快照”：先选择不存在的绝对 `.sqlite` 路径，再明确预览本地 RSS，最后单独确认敏感明文导出。挂载/打开设置不读取正文。预览返回八表行数、完整文件字节数、SHA-256 和五分钟有效期，不返回 URL、正文、笔记或缓存内容。计划 ID 一次性使用，拒绝同意、过期、取消、失败和不明结果后均不自动重试。关闭设置、禁用、刷新、gateway/目的地变化及卸载使旧计划和同意失效，迟到计划交还原 gateway 丢弃。

导出是标准 SQLite 3 文件，`meta.schema_version=2`，无需 WAL/SHM 即可只读打开。预览合同 `schemaVersion=1` 仅表示计划协议，不能当作数据库版本或 P42 JSON 格式。现有 RSS JSON 备份仍独立存在；它不包含离线翻译缓存和临时撤销记录，本批文件不是该 JSON 恢复器的输入。

| 表 | 内容 |
| --- | --- |
| meta | RSS 偏好与数据库元信息 |
| feeds | 订阅源、URL、刷新状态及问题详情 |
| articles | 正文、摘要、作者、URL、标签、已读与星标 |
| highlights | 划线、笔记与标签 |
| reading_progress | 阅读位置与版本 |
| undo_actions | 临时撤销内容，可能包含曾移除订阅/文章内容 |
| full_text_cache | 已保存全文、来源 URL 与抓取元信息 |
| offline_translation_cache | 离线翻译、翻译服务/模型和语言元信息 |

全部已保存行都进入快照，包括尚未清理的过期缓存和撤销记录。凭据库、其他工作区来源、仓库文件及外部附件未读取/复制；RSS 正文、URL、笔记、缓存或撤销内容自带的秘密不会自动脱敏。输出 0600，属于可读取明文，需用户明确同意。

## 一致性、结构与文件边界

使用既有持久 RSS 连接和 mutex，SQLite 读事务固定采集视图，再用 rusqlite 0.31 在线 Backup API 复制至独立内存库；不会直接复制 live 主库或 WAL，也不调用具有隐式清理/更新时间副作用的离线翻译读取接口。源库不迁移、恢复、VACUUM、checkpoint 或清理。

副本校验数据库完整性（quick_check）、外键引用、版本、安装版本已知对象、列属性、外键与索引结构；允许 ALTER TABLE 后列顺序差异，拒绝未知表/列/索引、视图和触发器。它没有重新执行 RSS 每项业务输入校验，也没有证明所有任意 DDL 文本语义或正文/URL可信。随后仅在副本 VACUUM，减少空闲页及已删除页残留，再验证并序列化，拒绝非 SQLite 头或需要 WAL 的输出。压缩不会删减任何当前表行，也不会清理源库。

主库完整页面大小和输出均最多 32 MiB，单个侧车 metadata 大小最多 128 MiB；同时最多两个计划，在线复制检查五秒步骤时限，Busy/Locked 不无限重试。其他 JSON 导出仍保留原 8 MiB 限额和 `.json` 扩展名。

只接固定 `$APP_DATA/RSSReader/reader.sqlite`，默认内存库、缺失和不可确认持久身份明确拒绝。目录需 0700；主文件需 0600、当前用户所有、普通文件和单硬链接；侧车只接受受私有目录保护的当前用户普通单链接文件、无执行/组或其他用户写权限。路径逐组件 descriptor/no-follow 验证，预览与执行重新核对根/目录/主文件身份及主库/WAL时间大小、同一连接 data_version、total_changes 和 schema_version。文件校验辅助逻辑仅检查侧车 metadata，不自行读取或复制侧车；SQLite 引擎通过既有连接正常读取 WAL，获得已提交内容。

目标在应用数据根和已初始化 Git 仓库之外，父目录必须已存在、安全、当前用户所有，目标必须不存在。复用 descriptor 锚定的私有暂存、fsync、读回、不可覆盖提交与文件/父目录身份再确认。执行前、提交前和提交后复验来源与有效期。外部 WAL 写入者仍可在读事务中提交；若发生来源变化，返回失效或结果不明。提交后才检测到变化时，已导出的私有文件可能存在且仍是预览绑定的完整历史快照，UI 不显示成功、不删除文件、不复用计划，用户需查验并选择新文件名。
