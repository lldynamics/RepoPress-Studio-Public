# P30：主编辑器安全退出与文章恢复包

2026-09-26，本地实施；macOS 比较基线仍为 `6857545`。本轮完成主编辑器当前文章的关闭保护，不代表全工作区退出事务已追平。

## 用户流程

1. 关闭窗口或请求应用退出时，Rust 先阻止退出并通知主界面。
2. 请先完成并关闭其他输入面板、返回写作区。原生文件选择、文件/网络操作、保存或 IME 输入仍在进行时，窗口保留，待完成后重试。后台 AI 流式请求须连同收尾持久化结束。
3. 关闭对话框冻结当前文档身份、基线与完整编辑文本，暂停恢复定时器和新的原生操作。可选择返回编辑、保存恢复草稿并退出，或导出恢复包并退出。没有未保存正文时，校验本机工作区状态再退出。
4. 正常路径原子写入、同步并读回主恢复文件。后端返回有效期 60 秒的一次性凭证；界面复验缓冲区仍相同，后端再次读回验证后才允许真正退出。取消、保存失败、缺失/损坏数据、凭证过期或快照漂移均保留窗口。
5. 自动恢复关闭时，不会静默开启；未保存文章需先保存到仓库，或显式导出恢复包。下次启动的恢复仍由用户确认，只载入编辑缓冲区，不覆盖仓库文件。

## 应急恢复包

选择目录后创建独立的 `RepoPress-recovery-*` 目录，既有文件不会被替换。目录内包含：

- `draft.md`：完整编辑文本，直接用文本编辑器打开即可取回。
- `recovery.json`：格式版本、原仓库和文章相对路径、保存基线、时间、正文 SHA-256 和字节数。
- `README.txt`：先保留原文件、再比对并手动合并的说明。

包不包含凭据、图片、附件、聊天、RSS、资料库或发布台账。Unix 目录/文件使用 0700/0600；Linux 子文件 I/O 绑定目录描述符，拒绝符号链接目标；写入及目录同步后核验每个文件的完整内容，执行退出前再次核验。包内容后来被改动或删除时拒绝退出。导出失败可能留下部分目录，但不会将其作为已完成的退出依据。

普通恢复稿保持 4 MiB/LF 限制；应急正文允许至 16 MiB，并保留原始文本，便于取回因大小或行尾被普通保存拒绝的内容。即使原仓库已移动或不可用，仍可依据已登记文档的缓存来源信息导出；这些信息不授予任何仓库写入权限。启动时忽略的损坏工作区文件不能通过退出操作静默重写为有效恢复证明。有未保存正文时要求导出；没有未保存正文时可明确选择保留原恢复文件并退出，该路径不写入文件，也不宣称原文件已校验或修复。
