# P51 合并清单投影与隐私重置确认

2026-10-05。本批在 P50 的完整重新捕获内构建合并后的清单，返回摘要、固定 SHA-256 与阻止原因。设置中心增加“生成投影 → 确认导入项权限关闭 → 一次性内存复验”。候选和当前资料库都不写入；复验成功仍不提供恢复执行能力。

## 合并规则

保留当前库所有资料、分类及当前字段，包括已有 AI/语义索引权限。候选中当前库没有的 ID 按 ID 排序追加。严格策略遇到同 ID 数据变化时阻止投影；“保留当前数据”策略跳过候选已有 ID，保留当前版本/历史。不同 ID 的分类名按现有资料库的小写规则比较，重名会阻止投影。

新增资料的 `allowsRemoteAiUse` 和 `allowsLocalSemanticIndex` 均置为 `false`。`resetPermissionItems` 只统计新增项中来源曾启用任一权限的数量。确认只表示理解关闭导入权限的处理方式；后续启用权限仍须逐条授权。内存投影的 `completedOperations` 为空，排除双方的旧执行凭据；磁盘中的凭据不变。只返回聚合计数和哈希，不返回合并清单、标题、正文或全部历史内容。

## 捕获、限制和计划

投影在 P49/P50 已打开的候选、当前清单和资源 witness 仍被持有时计算，然后完成原来的目录、文件、inode/stamp 复验。当前清单或保存资源不可核验、身份策略不满足、分类重名、容量超限、清单/引用无效或捕获变化时，结果阻止或命令失败，不能进入确认复验。

复用候选严格路径与私有权限协议、重复 JSON 键拒绝、全部历史引用/内容核验；当前资源每侧最多 1,024 个、32 MiB。合并后限制为清单 2 MiB、2,000 项、128 个分类、2,048 个去重资源、资源合计 64 MiB；原有正文/归档单项和历史规则仍适用。严格 JSON 解析最多 131,072 个节点，整个捕获有 5 秒预算。投影的每个资源必须属于已核验来源的 kind/digest/size/format 引用集合，同一 kind/digest 的重复引用不重复计量资源容量。

计划最多同时保留两份，绑定路径、当前应用库、策略、所有观察指纹与投影摘要；五分钟 wall-clock/monotonic 双重过期。`preflightKnowledgeMergeProjection` 先消费计划，再检查隐私确认与期限，重新打开并核验全部来源后比较指纹；同字节 inode 替换也会失效。失败、拒绝确认或重复调用后都须重新生成计划；discard 幂等。成功回执仅确认本次内存复验。

`consistentSnapshot=false`、`filesystemWrites=false`、`currentLibraryChanged=false`、`restoreReady=false` 保持固定。来源真实性、外部附件和未引用文件闭合仍未证明；`projectedManifestValidated=true` 只描述本批内存清单，嵌套 P50 资格报告仍保留原有 `projectedManifestValidated=false`。
