# 工作台 UI 对齐：第十六批

日期：2026-10-07。承接[第十五批比较目标与原文分区](ui-draft-comparison-alignment-2026-10-07.md)，补齐正文差异的双行号和可展开上下文。参考当前检出的 Mac `DraftVersionComparisonView.swift` 与 `DraftVersionComparisonService.swift`，没有刷新远端或最新 Mac 实机基线。

## 已实现

- 正文差异显示来源、目标两列行号和差异内容；来源在左，当前稿或另一历史版本在右。缺失行号留空，增删符号与颜色并用；空行、空白、花括号、中文及 HTML 字符串作为原文字面量显示。
- 每处变化附近保留三行上下文，至少能隐藏四行才折叠。支持逐段或全部展开/收起；展开显示原有行号、内容与顺序。所有变化行始终可见。完全无变化且足够长时保留首尾各三行，短文不折叠。
- 双行号区可获得键盘焦点，并通过横向滚动保留长行。表格具有列标题、数据行及单元格语义；折叠按钮提供 `aria-expanded` 和稳定的 `aria-controls`，控制的行组即使收起也保留。
- 切换语言保留表格、按钮、焦点及展开状态，不重新读取历史版本。切换来源/目标、当前稿文本变化或外层比较对象变化立即收起；A→B→A 不恢复旧展开。相同文本的目标切换由来源/目标身份 key 区分。

Front Matter 继续使用独立的原文差异容器。未闭合 Front Matter 的全文回退采用双行号；超限回退仍只显示原有统计与受控提示，不生成表格或折叠。

## 比较边界与 Mac 差距

本批只整理已有差异数组，不改变 LCS、增删顺序、统计、400 行/128 KiB UTF-8 上限、Front Matter 分区或恢复参数。纯折叠辅助逻辑为线性遍历，输出保留原始行对象引用。既有比较器规范化换行符，本批保持其产出的行文本，不声称保留原始换行字节。正文行号相对于正文分区；未闭合全文回退相对于全文。

当前 Mac 会折叠远离变化的上下文，即使只省略一行；完全无变化时不生成正文差异行。Linux 在本批采用至少四行、可展开和无变化首尾上下文的展示边界。字段级元数据语义对比、缓存、共享 in-flight 和后台计算仍待实施。

浏览器安全策略此前阻断本地页面；本轮没有重试或绕过，也没有截图、窗口宽度测量或像素对齐证据。WebKitGTK、GNOME/KDE、Wayland/X11、HiDPI、中文 IME、AT-SPI、真实键盘滚动及最新 Mac 实机仍待现场验收。
