# 工作台 UI 对齐：第四批

日期：2026-10-02。承接[第三批语言与主题](ui-language-visual-alignment-2026-10-02.md)，沿用[第一批](ui-workbench-alignment-2026-10-02.md)固定的 macOS 参考。本批完成写作检查器工具与本地诊断的简中/English 文案迁移。

## 已实现

- 查找替换的字段、范围、选项、匹配位置、预览、确认及受控错误支持双语。切换语言保留查询、替换内容、冻结选区、有效预览和进行中的 Worker，不重新运行操作或扩大替换范围。
- 固定文章大纲及章节操作支持双语，保留用户标题、折叠状态和所选章节。英文单章显示 `1 section`。删除确认按当前语言显示；取消仍不修改编辑缓冲区。
- 图片属性的 alt、说明、封面控件及操作反馈支持双语。用户路径与未提交的 alt/说明保持原文，编辑结果仍仅写入缓冲区。
- 内置 Markdown 诊断的标题、建议和定位/修复提示支持双语，包括标题跳级、重复标题、缺失 alt、脚注、裸 URL、列表空格、未闭围栏及内部链接目标。
- Front Matter 字段报告、检查上限提示与受控解析错误支持双语。报告在切换语言时保留；文稿改变后仍失效，定位使用生成报告时的精确原文。
- 查找、图片和快速修复向 App 传递源模板与参数，通知随当前语言渲染。写作、大纲及现有报告定位的通知也保存受控来源标签，避免“已从Writing panel定位”混合语言。

## 行为与数据边界

诊断增加可选展示描述，旧 `title/message/range/replacement/expectedText/readOnly`、规则检测条件和修复内容保持不变。Front Matter 仅增加受控错误的展示描述，解析和回写拒绝条件保持不变。

只有明确标记的本地 UI 模板和标签进入翻译。正文、标题、链接目标、查询、替换文本、alt、说明和路径是单次字面插值参数；未知诊断/错误保持原文。不解析或猜测任意后端错误文本。原有快速修复插入的 `[链接]` 等正文文本继续保持原样，不随界面语言变化。

语言不参与选区、Worker、预览、大纲折叠或报告的失效依赖。过期替换、Worker 超时、文稿漂移、无效 Front Matter 和只读控制仍拒绝写入。正文范围的 Front Matter 错误仅在原有拒绝原因与受控解析描述精确对应时本地化；未标记原因继续原样显示。

## 分工与工作树保护

主线程负责展示描述、诊断和解析错误模板、App 接线、跨组件测试、浏览器验收及最终整合。Sol high 独占查找替换组件与对应字典/测试；Luna medium 独占大纲和图片组件与对应字典/测试；Sol xhigh 独立只读复核。子代理没有继续委派。运行时没有 Terra，沿用前批的 Sol high 有界实现分工。

开工保存 2260 个源文件哈希和关键文件副本；最终基线缺失文件为 0。并行变化的备份设置、契约/Gateway、Rust 备份及配置模块、命令注册和 P41 文档全部保留，不归因为本批 UI 实现。本批没有提交、推送、合并、重置或清理工作树。
