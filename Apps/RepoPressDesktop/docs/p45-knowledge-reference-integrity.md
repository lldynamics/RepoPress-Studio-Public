# P45：资料清单与保存文件引用的只读完整性预检

2026-10-03，固定 macOS 比较基线 `2d2858fc5ebc3843d1a281026304c2551741691c`，Linux HEAD `97f1fd75e12b4b9606974890bfa317a7bac9b6e3`。保留已有本地及其他 UI 会话工作；本批没有 fetch、合并、提交、推送或真实用户数据导出。

## 实现范围

设置中心新增“资料引用完整性预检”。明确检查后读取固定 `knowledge-v1/manifest.json`，以其中所有历史修订的摘要连接 `blobs/<sha256>` 正文和 `archives/<sha256>` 离线网页归档。按类型/摘要去重检查文件；重复引用仍计入引用数，声明相同摘要却大小不一致时拒绝清单。历史修订的正文和归档都在范围内，不限于当前条目；完整报告仅返回数量、状态、问题分类、清单摘要和固定限制，不返回资料标题、来源名称/路径、URL、正文、归档或文件路径列表。

| 输出 | 含义 |
| --- | --- |
| 清单状态 | 已验证、缺失、不安全、不可读、过大、无效、不支持版本或读取期间变化 |
| 引用数/唯一文件数 | 从全部保存修订计算，不受检查文件上限截断 |
| 已验证/缺失/不安全/不可读/无效/变化/省略 | 互斥文件数量分类，合计等于该类型唯一文件数 |
| 归档缺失/截断/未知 | 对应保存元信息的引用数，不是重新解析出来的内部资源数量 |
| checked / partial / unavailable | 本次检查完成、部分结果或不可用；界面均使用中文说明 |

清单缺失不证明空库，计数保持未知；合法空清单可完成本次检查。当前仅支持 Linux 持久清单版本 4，1–3 和未来版本明确不支持，不做隐式升级。报告 `schemaVersion=1` 是预检合同版本，与源清单版本独立，也不是 macOS 的资料备份包格式。当前条目必须与最新修订的大小、摘要、编号和归档元信息一致，拒绝重复 ID、未知文件夹、非法摘要/来源、未知引用字段和结构不一致。

正文核对字节数、SHA-256 和 UTF-8；归档核对字节数、SHA 和已有 HTML/MHTML 格式判别。不同修订共享同一归档时，只读文件一次，但每个引用的归档缺失资源/截断/未知完整性状态都计数。保存归档可能已带内部缺失资源或截断；可选内部资源计数缺失时也明确标为部分，不能因为其文件摘要正确而把资料整体说成完整。

凭据、其他工作区来源、仓库当前文件、外部引用、未被清单引用的文件及运行时状态排除。原 PDF、外部图片/附件、Markdown 与 HTML/MHTML 内的远端/相对链接不会被解析、抓取或沿引用打开；归档内容不会渲染。未检查未引用文件，不列“孤儿”或推断可删内容。持久完成回执没有正文引用，预检不恢复/执行其业务状态。

## 只读与有界读取

预检拥有独立的固定应用根句柄，不调用 `KnowledgeLibraryStore::new`、`status`、加载迁移、导入/删除/导出或垃圾清理；这些既有接口可能创建目录、调整权限或删除未引用文件。对源只做文件/目录读取，不创建文件、改权限、重写清单或清理数据。

清单最多 2 MiB；资源最多尝试检查 1024 个唯一文件、合计读取 64 MiB；正文单文件 5 MiB、归档 24 MiB，并保留现有资料/历史/唯一字节容量约束。读取及最后逐文件复验步骤检查五秒时限，底层单个文件系统调用不能被该时限抢占。超限引用保留完整声明数量并归为省略，报告部分；不会截断内容后假称验证成功。

使用现有 Linux descriptor/no-follow 路径遍历。资料/正文/归档目录必须当前用户所有、0700，文件必须当前用户所有、0600、普通单硬链接文件；先用 O_PATH 核对类型，再通过 `/proc/self/fd` 打开已经核对的普通 inode，避免 FIFO/设备/符号链接在检查前被内容打开。读取分块受字节/时间预算限制，读取前后核对文件 descriptor 和命名空间身份、长度、mtime/ctime。全部读取后再次逐项核对已尝试文件（包括缺失或不安全条目）、清单及目录，变化会使报告失效或部分，撤回受影响的已验证计数。根或目录替换不会把读取扩展到新外部路径。

这些逐文件观察并非跨文件原子快照。`allReferencedFilesVerified` 只表示本次范围内保存文件均通过检查；`consistentSnapshot=false`、`backupReady=false` 永远保留，不授权导出、恢复、清理或其他写入。文件之后仍可能变化。

## 短时报告和界面失效

报告在内存保存五分钟，最多两份；丢弃幂等。重新核对先消费旧 ID，重新执行完整有界检查并返回新 ID，无法重放。只有前后两份均完成本次检查时才给出未变化/变化，依据清单内容及所检查来源身份/时间等观察比较；部分/不可用情况始终无法确定，不把省略内容算作相同。

挂载/打开设置不读取正文；检查和重新核对都有明确按钮。重复检查先同步丢弃旧报告。关闭、禁用、刷新、gateway 变化、卸载、到期或主动丢弃撤销绑定；旧 DOM 与迟到回执不能回填新状态。迟到或带有效 UUID 的无效报告交回原 gateway 丢弃，避免占用容量。UI 严格核对协议/源版本、TTL、SHA、固定限制/排除、资源分区与数量关系；没有导出、删除、恢复或自动重试按钮。
