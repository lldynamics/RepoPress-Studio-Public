# P25：批量标签与分类维护

本批以最新 macOS `main` 的 `6abd42a8bbf4254961498c359cd7e9ef037f2fe7` 为参考；相对先前 `58d1cf3`，`MetadataBatchMaintenanceService` 的合同没有变化。共享工作区的编辑器增强使用 P24 编号，本批独立记为 P25。

## 使用路径

在仓库文件区或命令面板打开“批量标签与分类”，筛选并选择最多 20 篇文章，选择标签/分类及添加、移除或重命名。先生成修改预览，查看各篇原值、新值或无法处理的原因；确认后逐篇执行并显示结果。

当前有未保存修改的文章不进入候选；可先保存再重新打开/预览。执行期间不能关闭面板或继续编辑、切换。涉及当前已保存文章时，结束后重新读取磁盘，避免旧编辑缓冲将批量结果覆盖。结果不表示全批事务：某篇冲突或失败不会撤销其他已经成功的文章。

## 字段与文件保护

- 仅操作 `tags` 或 `categories`。每个计划冻结仓库会话、目录身份、路径、操作、目标字段原值与拟写入值，5 分钟过期，每个会话保留最新计划，执行前消耗一次。重启后计划失效。
- 执行时重新打开每篇文章。如果目标字段变化，报告冲突；如果只有正文或其他字段变化，则基于最新文本重做字段变换。不会拿预览时的整篇旧正文写回。
- 复用仓库会话、路径限制、UTF-8/只读判断、SHA-256 保存复验、原编码/换行形式及原子文件替换。预览不会写文章；执行先保存修改前历史版本，再写文件，历史失败则该篇不写。
- 预览及执行使用临时文稿会话，结束后释放；不替换编辑器自己的会话。目录身份变化、符号链接、越界路径和不支持格式拒绝处理。
- 结果逐篇区分已更新、无变化、冲突和失败。发生错误时可能已有部分文章写入，需核对磁盘与历史记录，再生成新计划。操作日志记录一次批量动作，部分失败记为失败，不记录字段内容、文稿正文或原始路径。

## 支持边界

这是受限 Front Matter 子集，不是完整 YAML/TOML 编辑器。支持已存在且没有歧义的简单顶层结构，目标字段使用单行 JSON 风格字符串数组，或受限 YAML 缩进字符串列表。缺少目标字段时可添加；没有 Front Matter、复杂嵌套、多行值、别名/锚点、合并键、目标键歧义或重复等会被拒绝。其他字段及正文按文本片段保留，不全篇重新序列化。

添加和移除支持逗号、中文逗号或换行分隔的值；重命名限定单个源值到单个目标值，拒绝制造重复值。按大小写不敏感匹配，不实现 macOS 的区域相关音调折叠或多对多重命名。每项最多 128 个 Unicode 字符，每字段最多 64 项，操作输入及集合序列化受 8 KiB 限制，Front Matter 上限 64 KiB。每批最多 20 篇，单篇沿用 4 MiB 文件上限，不进行全仓库隐式批改。

不搬迁附件、不改正文、不运行站点脚本。浏览器演示和没有此能力的旧后端显示不可用。本批也没有修改站点配置或通用草稿库。

## 代码链路

`MetadataBatchCenter` → `RepositoryGateway.planMetadataBatch/executeMetadataBatch` → `plan_metadata_batch/execute_metadata_batch` → `MetadataBatchStore` → `transform_metadata_field`、`DraftHistoryStore`、`RepositoryStore.save_document`。

前端与 Rust 注册、能力标记、浏览器演示边界和操作日志同步接入。变换后的字段会重新解析并核对拟写入值，防止生成下次无法读取的内容；带 `#`、`&`、星号或引号的字符串按引用数组保存并通过往返测试。
