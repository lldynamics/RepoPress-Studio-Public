# 工作台 UI 对齐：第十二批

日期：2026-10-05。承接[第十一批候选检查与编辑菜单](ui-candidate-editing-menu-alignment-2026-10-05.md)，补齐 Slash 菜单、Markdown 片段库、工具栏自定义和快捷键帮助的简中/English 呈现，调整相关长文本和对话框布局。继续使用既有固定 macOS 参考，没有刷新实机比较基线。

## 已实现

- `MarkdownSlashMenu` 的标题、ARIA、空状态、内置命令标签与说明支持双语。主窗口为内置片段投影提供明确的 ID 标记；组件在 ID 标记及原始标签、说明均匹配时才翻译。
- `MarkdownSnippetLibrary` 的类别、表单、按钮、提示、内置片段标签与说明支持双语。控制状态保留来源文案，在显示时使用当前语言；插入和删除确认使用双语外层说明，并把名称单次插入。
- `MarkdownToolbarCustomization` 的标题、格式名称、排序 ARIA、按钮、忙碌状态和本地保存失败提示支持双语。后台 `Error.message` 保留原文，即使它恰好与词典键相同。
- `MarkdownShortcutHelp` 的说明、操作标签、搜索提示和空状态支持双语。快捷键字符本身保持原值，仍只列出已有实际绑定的命令与既有编辑器操作。
- Slash 菜单说明和空状态使用主题变量；菜单与片段长名称允许换行。两个写作对话框使用 border-box 宽度，长行允许换行，窄窗口下自定义排序行和页脚调整排列。深色自定义错误提示补齐颜色。片段样式通过现有 `aria-labelledby` 限定到片段库，其他共用片段面板保持原有规则。

## 数据与交互边界

核心 Slash 命令仅按 `markdownSlashCommands` 对象身份翻译；克隆对象、未标记的片段投影和修改过原始说明的投影保持原始文本。片段库仅按内置对象身份翻译，用户名称、说明、快捷方式、模板和花括号内容保持字面值。点击与键盘选择回调收到原始命令对象，没有把翻译后的显示对象交给编辑逻辑。

所有插入模板、模板变量、选区、编辑命令、帮助键盘字符、已保存自定义片段与排序 ID 保持原值。`{{title}}`、`{{slug}}`、`{{date}}` 通过单次参数插值展示，不发生二次替换。搜索与过滤仍使用原有原始文字和快捷方式，本批没有新增按翻译后的显示名称搜索；英文关键词或片段 shortcut 仍按既有规则查询。

语言没有加入打开、存储读取、持久化、焦点或原生 dialog effect 的依赖。切换语言不会重开弹窗、重置查询/分类/表单、清除选区或焦点、重发保存、触发片段回调。保存时的 busy 与关闭保护、删除确认、存储失败回滚、作用域切换及已有输入限制保持原有行为。片段编辑仍使用原有表单字段，不改变已有 `selectionToken` 的编辑持久化行为。

`App.tsx` 仅增加已知内置片段 ID 的展示标记，没有修改 Slash 搜索、命令生成、插入或导出 notice。全局 i18n、写作辅助函数、契约、Gateway、Rust 和 `App.css` 未纳入本批改动。同期 P51 合并投影由另一条任务实施，全部保留，不纳入本批实现或 Rust 验收。

## 分工与工作树保护

Luna medium 独占 Slash 菜单；判断较多的片段库实现由 Sol high 负责；Sol xhigh 执行独立只读审查与首次全量前端测试；主线程在同期投影源码再次冻结后刷新最终组合门禁。旧版 Sol 在实施与审查期间出现容量限制，对应工作切换到可用的 `gpt-6.1-sol` 继续。主线程负责工具栏/帮助、共享内置词典、唯一主窗口接线、词典门禁、CSS、整合和最终验收。没有子代理继续委派，写入文件不重叠。

开工保存 2402 个文件哈希与 13 个关键源文件副本。本批共 16 个源码/测试文件（8 个已有、8 个新增），另新增本篇记录并更新第十一批覆盖矩阵。限定源码组合 diff 为 844 行。最终审查补强了未标记内置投影、克隆命令、修改说明的已标记投影以及原始回调对象身份测试，并修正共享“正文”“分隔线”的规范译文。包体检查曾发现编辑器静态依赖超过 1300 KiB 预算约 0.2 KiB，主线程复用全局已有的 12 个相同译文，补测所有 13 个核心命令，保持预算规则不变。
