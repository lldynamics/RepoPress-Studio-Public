# P44：普通草稿与草稿历史的单库快照

2026-10-03，macOS 对照继续固定在 `2d2858fc5ebc3843d1a281026304c2551741691c`，Linux HEAD 为 `97f1fd75e12b4b9606974890bfa317a7bac9b6e3`。本批没有 fetch、合并、提交或推送，保留已有本地和并行 UI 改动。

## 用户流程与范围

设置中心新增“草稿数据库快照”，每次选择普通草稿或草稿历史其中一库。选择不存在的绝对 `.sqlite` 路径，明确生成预览，单独同意敏感明文后一次性导出。打开设置不触发正文读取。预览只显示表行数、文件大小、SHA-256 和五分钟有效期，不展示条目标题、来源路径或正文。切换来源需重新选择路径、预览和同意；取消、到期、关闭、禁用、刷新、gateway 变化和卸载使旧计划失效。迟到计划通过原 gateway 丢弃；执行不自动重试，结果必须与来源、计划 ID、目标、大小和 SHA 全部对应。

| 来源 | 固定应用数据文件 | 全部保存内容 |
| --- | --- | --- |
| 普通草稿 | `GeneralDrafts/general-drafts.sqlite` | `general_drafts` 的正文、标题、来源信息、revision 和时间 |
| 草稿历史 | `DraftHistory/history.sqlite` | `drafts` 身份映射、`versions` 历史正文、`recycled_drafts` 回收正文，覆盖所有仓库 |

输出为可独立只读打开的标准 SQLite 3 文件，无需 WAL/SHM。两库目前没有持久化版本标记：`sourceSchema=unversionedInstalledLayout` 表示以当前安装代码的已知结构核验，`schemaVersion=1` 仅是预览合同版本；不向源库添加版本、不迁移源数据。

凭据存储、未选其他数据库、仓库当前文件、外部附件、内存转移计划和撤销状态固定排除。Markdown 中的图片/文件引用仅作为正文保留，不沿引用读文件。标题、路径、URL 和正文可能自带秘密，不自动脱敏；历史库也会导出回收正文。单库快照不承诺跨数据库/仓库文件的同一时点，也不保存待执行转移计划。

## 一致性、内容和文件边界

通过所选来源的既有持久连接和 mutex，在读事务中固定视图，在线 Backup 到独立内存库。仅对副本校验、VACUUM 和序列化；不新建/重开源 store，不 checkpoint、修复、清理或写入源数据库。默认内存库、缺失文件或无法确认原有持久身份拒绝；另一未选数据库缺失/损坏不会导致它被读取。

复用 P43 的 `sqlite_snapshot` 机制：主库完整页大小及输出均最多 32 MiB，侧车 metadata 最多 128 MiB，复制步骤检查五秒时限，Busy/Locked 不无限等待。本功能最多两个短时计划；RSS 的计划容量独立。主库/目录需私有权限、当前用户所有、普通主文件且单硬链接；路径逐组件 no-follow，以 descriptor、dev/inode、模式、来源文件时间/大小和连接 revision 复验。侧车只核对 metadata，WAL 由既有 SQLite 连接读取。

副本进行 quick_check、外键检查及当前已知表/列/索引结构核验，拒绝未知版本标记、对象、列、索引、视图和触发器；允许已知迁移的列顺序差异。草稿额外核对 UUID、路径、时间、revision、UTF-8 正文最多 4 MiB、记录字节数和 SHA。历史还核对 repository key、reason 及版本/回收行是否引用已有草稿身份；不把当前映射路径强制等同于旧版本/回收路径，也不把列表显示上限当成整库数量上限。这些检查不证明任意 DDL 文本语义、正文可信、附件闭合或可恢复。

普通草稿 SHA 必须对应保存正文的 UTF-8 字节，正文为 LF。历史正文是文档读取器统一换行后的文本，基线 SHA 则对应仓库原始字节；因此只额外允许 LF/CRLF 与可选 UTF-8 BOM 四种已知原始表示的摘要，保留原字段，不重算覆盖。历史没有单独记录原文件编码/换行标志；摘要校验不提供精确编码恢复能力。真实 RepositoryStore→history_context 四编码夹具覆盖了这一区别，格式正确但不匹配的摘要仍拒绝。

目的地必须在应用数据根和已初始化 Git 仓库之外，父目录已存在、安全且当前用户所有，目标不可已存在。复用私有暂存、fsync、读回与不可覆盖发布，成功文件为 0600。执行前、提交前、提交后复验来源和有效期；计划先消费再检查同意/执行，失败后不复用。若外部写入或路径变化导致发布后结果未明，私有文件可能已存在且仍是预览的完整历史快照；UI 不显示成功、不删除文件，需查验后选择新文件名。
