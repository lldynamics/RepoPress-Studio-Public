# P63：确认式启动与 HTTP 页面就绪验证（2026-10-15）

接续 [P62B](p62b-article-state-changes.md)，本批补齐 [P63 计划](macos-linux-comparison-2026-10-13.md)的页面就绪与过期上下文保护。原先端口可连接后直接嵌入页面；现在先生成一次性启动计划、确认信任仓库，再启动固定 Hugo/Zola，随后核验当前文章或首页的 HTTP 响应。只有当前目标通过检查才显示“页面已就绪”并嵌入。

## 启动和配置边界

- 仍只解析受信任系统/用户工具目录中的 Hugo/Zola；不接收可执行文件路径或任意参数，不执行 Astro/Jekyll/npm 仓库脚本。原有信任确认保留，确认显示计划绑定的运行时。
- 服务端保存随机计划 ID，五分钟单调时钟有效期，一次性原子消费；同会话的新计划会作废旧计划。旧的仅传 session 与布尔确认的启动调用不再满足 IPC 合同。
- 计划绑定规范仓库根、站点类型、运行时路径/对象/内容指纹、配置快照及所选文稿 ID、revision、baseline SHA、相对路径和磁盘内容。执行前后复验；失败不能复用计划。
- 配置范围是根目录的 `zola.toml`、`hugo.toml/yaml/yml/json`、`config.toml/yaml/yml/json`，以及 `config/` 下的有界目录树。包括缺失/存在、新增/删除、对象身份与内容摘要；拒绝符号链接、特殊文件、超过 256 个目录/文件项、config/ 内 8 层子目录、单文件 1 MiB 或合计 4 MiB。文稿上限 4 MiB，运行时上限 256 MiB，摘要使用固定缓冲区读取。
- 这不是完整生成器配置模型或全站快照；主题、附件、其他文章与外部资源不在本次快照内，生成器仍按既有信任边界处理仓库内容。未保存编辑明确提示不会进入真实预览。

## 页面探测与并发

只探测本次预览 ID 所属的动态回环端口，路径由服务端从冻结文章路径或 `/` 选择。请求直接连接数值 `127.0.0.1`，不使用代理或 DNS，不接受 renderer 提供任意 URL。GET 仅读取响应头，最多 64 KiB；每次请求不超过一秒，总等待不超过十秒，支持取消轮询和有界重试。

最终 2xx 才表示该页面在检查时可用；404/500、超时、非法响应、协议升级及跨源/循环重定向均不能就绪。同源重定向有界跟随，最终 iframe 使用已核验地址。空正文或持续流式正文不会拖住响应头检查；不保存/展示响应正文，也不声称验证了文章正文、完整站点构建或线上部署。

消费计划时立即登记待启动代次，后发启动或定向停止可取消较早的慢请求。生成器启动、进程终止和 HTTP 等待均不持共享状态锁；实例所有权防止旧启动覆盖新实例，也防止旧清理误杀新进程。容量同时计入活动与已保留启动；提前读取尚未安装的实例不能取消启动。

页面检查前、重试中及返回后都验证同一实例与子进程存活，返回前再验配置和文稿。前端分别绑定站点、文稿、完整编辑内容、保存/打开/编辑代次与页面目标；旧计划、旧文章/首页响应和旧错误不能回填。确认后仍有同步上下文门槛，可识别同批编辑后改回原文的情况。

停止命令必须提供实例 ID；停止失败保留可重试入口。页面结果是一次检查的证据，没有常驻健康监控。需要时点击“重新验证页面”；日期、Git 推送和页面 2xx 都不表示线上已发布。
