# 工作台 UI 对齐：第三批

日期：2026-10-02。承接[第二批检查器与状态栏](ui-inspector-status-alignment-2026-10-02.md)，沿用[第一批](ui-workbench-alignment-2026-10-02.md)固定的 macOS 参考。此批交付主工作台语言偏好与明暗主题反馈调整，完整应用翻译继续分批迁移。

## 已实现

- 设置中心新增“界面语言”：简体中文、English、跟随系统。点击保存后应用，不因选择选项就提前持久化；恢复编辑器默认设置保留语言偏好。
- 偏好通过原有工作区设置 Gateway 保存到 Rust 工作区状态；没有新增语言命令。旧状态缺少 `uiLanguage` 时继续使用中文。前端归一化无效值为中文，Rust 拒绝非法语言值。
- 跟随系统取浏览器/WebView 的语言列表中第一个支持的中文或英文语言；未支持的系统语言回退 English。监听 `languagechange`，同步更新 `html.lang`。这不是桌面系统语言服务或第三种语言的支持声明。
- 主导航、仓库工具栏、视图栏、文件搜索、站点切换控件、命令面板及其命令说明、设置中心已有选项、状态栏和光标工作流支持中英文。写作格式工具栏、属性字段、SEO 检查器控件、预览控件与工作区 ARIA 文案同步切换。
- 常见启动/保存/恢复/冲突/阻止导航静态提示覆盖英文。打开仓库、文章和恢复工作区的通知保留源模板与参数，切语言时即时更新。主工作台未保存内容的仓库、站点、文稿和新建文章确认框也按界面语言显示，取消行为保持一致。
- 字典仅用于显式 UI 文案。正文、文件名、路径、仓库名称、属性值及网关提供的未知错误/只读原因原样显示。参数只替换一次，不递归翻译、不作为 HTML 渲染；未知键安全回退，包含原型属性名称的键也不会异常。
- 使用固定组件与文档键切换语言，保留正文编辑器实例、未保存正文、仓库搜索、文内查找和未提交标签输入。更改语言不开放只读演示的保存或格式操作。
- 主工作台警示、恢复和保存反馈使用明暗主题语义颜色；导航英文长标签可换行，提示文本可换行，不扩大页面宽度。

## 多模型分工与工作树保护

主线程负责语言架构、偏好契约与 Rust 持久化、App 接线、文件/命令导航、集成测试、视觉主题、浏览器验收和最终整合。Luna medium 独占设置/导航/状态/光标文案与组件，以及最后的 shell 字典；Sol high 独占写作、属性、预览和布局控件；Sol xhigh 只读独立复核。子代理没有继续派生代理。运行时无 Terra，判断较多的有界编辑包继续使用 Sol high。

工作开始时保存 2241 个源文件哈希与主线程关键原文件。最终基线缺失文件为 0。并行新增的备份契约、Settings 备份段、Gateway、Rust 注册及其他源文件全部保留；这些不归因为本批实现。没有提交、推送、合并、重置或清理工作树。
