# P47：独立资料包校验与内存隔离预检

日期：2026-10-03。沿用已刷新 macOS 对照基线 `2d2858fc5ebc3843d1a281026304c2551741691c`；本地 HEAD `97f1fd75e12b4b9606974890bfa317a7bac9b6e3` 未变化。

## 实施范围

接续 [P46 保存资料包导出](p46-knowledge-saved-package-backup.md)，设置中心增加原生单文件 JSON 选择、显式检查、五分钟一次性报告、取消和重新读取后的内存隔离预检。它独立读取选中的包，不依赖当前资料库，也不初始化、迁移、清理或改写资料库。浏览器演示四个入口均拒绝调用，不把不可用伪装成成功。

本批隔离暂存限定为短暂内存解码：预检重新核对来源，将包内清单和全部引用资源解码到独立内存对象，返回计数后释放；不会创建磁盘目录、持久副本或可恢复句柄。清单保留标题、来源 URL、分类及已保存偏好等元数据；报告只返回选定路径、数量、大小、摘要、固定边界和有效期，不返回标题、URL、正文、清单、base64 或原始清单摘要。资料包为未加密明文，界面明确提示。

## 不可信包协议

仅接受 P46 `repopress-knowledge-saved-files` 格式 1、源清单版本 4、`applicationSavedKnowledge` 保存范围。外层和资源对象字段必须精确，递归 JSON visitor 在任何对象深度拒绝重复键，保留 serde 默认递归深度限制；默认 `Value` 的重复键覆盖行为不能进入校验路径。拒绝未知字段、未知版本、尾随 JSON、非预期布尔标志和排除项；操作回执必须为空。

对包内清单按与 P46 相同的 `serde_json::Value` 紧凑序列化计算 SHA-256，调用纯引用投影，验证分类、资料身份、当前/历史修订、大小、内容地址及引用完整性。不使用会迁移或收集垃圾的资料库加载入口。原始清单摘要因导出清空回执而无法重新计算，只校验其 64 位小写十六进制语法；报告固定 `sourceManifestHashVerified=false`，即便该字段格式合法也不承诺它正确。

资源必须与投影得到的唯一引用集合完全一致。正文仅为 `blobs/<sha>`，归档仅为 `archives/<sha>`；重复、遗漏、多余、错误类别/路径/摘要或大小均拒绝。资源 path 只作内存键比较，从不用于文件 I/O；拒绝路径穿越。base64 必须为 canonical 标准编码，声明长度与编码长度、解码长度匹配，实际内容通过既有 UTF-8/HTML/MHTML 格式及摘要校验。保存归档的缺失资源计数大于零、截断或计数未知拒绝；归档内部附件与外部引用仍未实现语义闭合，保存的 URL 字符串保留但不会获取其内容。

上限：JSON 包 48 MiB、紧凑清单 2 MiB、唯一资源 1024 个/32 MiB、JSON 值节点 131072、一次读取及解析/解码合作式时间预算 5 秒。分块读取和递归解析检查预算；资源声明和编码长度先于解码分配校验，最终摘要/来源复验后再检查时间。系统文件调用不是可抢占超时。所有检查/预检串行持有 store 锁，避免并发 IPC 放大解析内存；报告最多两份，仅持有摘要/统计及文件描述符，不保存包内容。

## 来源和一次性边界

只读取显式选择的绝对、小写 `.json` 路径，最长 UTF-8 4096 字节；拒绝 NUL、`.`、`..`、空路径分量和别名。父目录必须存在、当前用户所有且不可被组或其他用户写入，逐级 nofollow descriptor 遍历；源文件须当前用户所有、精确 0600、regular、单硬链接且大小在预算内。O_PATH 先分类 inode，FIFO、设备和链接不会作为内容打开。读取 held inode 前后比较 inode、权限、链接数、大小、mtime/ctime，以及固定父目录和当前文件名；不会修复源权限或删除任何源文件。

预检开始即消费报告，失败/过期/漂移也不能重试同 ID；discard 幂等。单调五分钟时限与发布的墙钟失效时间同时检查，避免时钟前移后直调 IPC 越过界面有效期。预检重新读取 held inode，比较包 SHA 与大小，重做全部解析/引用/解码校验，最终复验来源及两个时限。它是有界逐文件校验，`consistentSnapshot=false`、`filesystemWrites=false`、`currentLibraryChanged=false`、`restoreReady=false`。

界面绑定来源路径、原始 gateway、启用/禁用/刷新上下文与渲染闭包，同步 refs 阻止双击和旧 DOM 检查新文件；上下文变化、换源、重新检查、取消、卸载和到期丢弃报告。可识别 UUID 的迟到/无效结果交回原 gateway；报告及预检结果顶层字段、计数关系、版本/标志/预算、摘要、ID、路径与有效期均需符合固定合同。
