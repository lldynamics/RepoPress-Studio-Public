## 已接通的行为

选区 AI 和连续对话都使用 `AiConnectionPanel`。点击“获取模型列表”或“测试连接”先生成本地计划，展示服务地址、模型、请求说明和有效期；只有点击“确认请求”才执行。模型列表允许尚未选定模型，文本探测必须指定模型。探测仅发送固定 `Reply with OK.`，不附带文章、资料或聊天历史。

- 保留用户输入供 Rust 验证，仅在比对时规范化 URL；尾斜杠、主机大小写与默认端口的等价写法不会再静默丢失计划。根路径仍保留 `/`，不擅自添加 `/v1`。执行回传已经审阅的规范端点。
- 计划同时校验 provider、operation、model、endpoint 和实际 request URL；结果核对计划 ID、配置及对应成功状态。不匹配时明确提示重新生成，拒绝展示成功。
- 过期计划自动退出确认状态；执行开始即清除旧确认卡，失败后必须重新生成。同步防重入保护覆盖同一事件中的重复点击。
- 配置、凭据版本、启用状态变化及组件关闭会使旧请求失效。迟到的计划或结果不能覆盖新状态；这不等于取消已经到达远端的 HTTP 请求。
- 鉴权、权限、端点策略、网络、限流、超时、响应大小/格式和本机密钥环错误分别提供固定中文引导，不回显服务原始错误内容。
- 模型筛选覆盖所有已返回模型，每次最多展示 50 个匹配项；能够筛到最初 50 项之外的模型。后端仍最多接收 200 个模型，不自动请求后续分页，列表不完整会给出明确说明。

## 一次性计划的后端修正

过去命令层先检查服务配置并读取凭据，再进入 `AiConnectionStore::execute` 消费计划。如果配置验证或密钥环读取返回错误，原计划可能仍留在存储中。普通凭据缺失返回 `None` 的路径原本已由 core 消费，本轮重点修复前置准备直接报错的路径。

现在命令层先调用 `take_execution` 消费计划，获得字段私有、不可克隆的执行对象，然后读取凭据。任何准备失败都会丢弃执行对象，不能恢复原计划。执行时再校验有效期、配置和凭据指纹；凭据读取期间过期也拒绝请求。IPC 名称和 TypeScript 合同保持兼容。

## 保留的边界与下一步

本批完成模型列表与小型文本探测的本地集成收尾，未验证真实 Ollama/外部 AI 服务或原生桌面。没有新增模型下载、后台探测、自动重试或扩展发送内容。浏览器演示继续拒绝连接计划和执行。

模型名称与一次文本响应不能证明流式、工具调用、结构化输出、视觉或全部 API 可用。更完整的能力证据、引擎/Codex 准备和站点写作风格仍在差距清单中；不以本轮通过宣称完整 macOS AI 对齐。下一项建议为安全退出与恢复包，再接持久发布执行记录和只读结果核实。
