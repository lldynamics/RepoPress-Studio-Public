# P62B：draft/ready 预览确认变更（2026-10-15）

接续 [P62 只读投影与定位](p62-article-state-projection.md)，本批为已识别站点内的可写文章增加“预览设为草稿 / 预览设为待发布”。预览展示文稿路径、原始字段、变更后字段及日期/标题/线上证据警示；确认后只修改当前编辑内容并标记未保存。取消不修改文本，焦点返回入口；确认后仍需普通“保存”才写盘。

## 格式和证据范围

- 只允许 `draft` / `ready`，对应明确 `draft=true` / `draft=false`。不会通过按钮设置 `published` 或 `localOnly`，待发布不等于已发布，也不启动 Git、站点预览或网络请求。
- 继续采用 P62 保守的单行 YAML/TOML 子集和 256 KiB UTF-8 上限。只读、未知站点、目录外文章、通用草稿、缺少 Front Matter 或无法确认的结构均不能变更。已有合法 Front Matter 缺少 draft 时，只在结束分隔符前插入一行；不会自动创建 Front Matter。
- 已有字段只替换布尔 token；缺字段只插入一行。所有其他原始字符，包括未知隐私/发布字段、注释、日期时区、BOM、LF/CRLF/mixed、正文和 Emoji，保持原样。修改后重新投影并检查大小，不能通过插入绕过上限。
- 日期缺失、无效、未来或时区未核验等问题保留警示；它们不制造调度或线上成功。没有新增到期提醒或文稿绑定部署证据。

## 预览失效与编辑器保护

计划绑定仓库会话、站点/内容目录、文稿 ID/路径、保存版本/SHA、完整文本及编辑/打开/保存代次。编辑后改回原文、切换文章/仓库、离开再打开检查器、保存开始或冲突、退出冻结及其他写入活动都会使旧计划失效。

App 在异步加载前后复验当前上下文，确认时从当前内容重新生成计划；不信任回调提供的目标、字段范围或结果文本。同一计划只消费一次，重复点击及并发应用拒绝。最终按重新生成的单次局部编辑提交到当前 CodeMirror 实例，以完整历史隔离保证状态变更与前后输入分别撤销/重做。

普通保存继续使用既有 document/session 与 baseline SHA，不绕过冲突保护或创建新的写盘接口。没有新增 IPC、数据库或持久化格式。`@codemirror/commands@6.11.0` 已在原锁文件中，本批只把直接使用的历史隔离依赖显式声明，不升级依赖版本。

CodeMirror 现在仅按 LF 拆行，保留原稿中的 CR，使源文本和 UTF-16 字段位置一致；实际 CRLF/BOM/mixed 应用和撤销均验证。普通 Enter 仍插入 LF，行尾编辑可能产生混合换行；完整换行策略属于独立编辑器改进，本批不宣称自动保持新增行的原始换行风格。
