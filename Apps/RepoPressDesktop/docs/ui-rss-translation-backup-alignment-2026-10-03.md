# 工作台 UI 对齐：第九批

日期：2026-10-03。承接[第八批阅读与资料库](ui-reader-library-health-alignment-2026-10-03.md)，继续沿用首批固定的 macOS 参考。本批完成 RSS 单篇/批量翻译和六个已有工作区备份面板的简中/English 迁移，并补齐主题和窄窗口布局。没有刷新 macOS 比较基线，不宣称最新实机像素一致。

## 已实现

- `RssTranslationPanel` 的范围、策略、方式、语言、端点/模型提示、术语表、凭据、计划、结果、后备方式和本地延迟消息支持双语。
- `RssBatchTranslationDialog` 的范围、数量、并发、目的地、任务阶段、受控失败、确认、暂停、恢复、最小化和缓存提示支持双语。
- 工作区元数据备份预检、资料引用完整性预检、资料 JSON 备份、配置 JSON 备份、RSS SQLite 快照和草稿 SQLite 快照支持双语。报告原字段、遗漏、SQLite 一致性提醒、确认说明及结果未明状态均保留；日期、数量、字节按当前语言展示。
- 备份卡片使用设置中心的字号、间距、按钮和语义警告颜色。RSS 系统阅读主题跟随工作台明暗颜色；批量翻译的状态与警告采用同组语义颜色。窄阅读列的翻译表单改为单列，长英文提示和按钮可换行。

## 行为与数据边界

语言只改变呈现，没有加入请求、加载、缓存或扫描 effect 的依赖。翻译请求、缓存键、冻结输入、批量队列、并发、暂停和最小化行为保持原有身份。切换语言不重复发送，不改变选择、配置、术语表、令牌输入、计划或结果；确认使用点击时的语言。

原始 Feed/文章名、正文、译文、模型、端点、令牌、未知后端错误和警告保持字面内容。后端语言字段若恰好是 `日本語` 等词典同名字符串，也不误当作受控语言代码。批量本地错误拥有独立展示来源，同名后端错误仍保留原文。已知受控凭据代码与单篇安全提醒沿用已有明确映射。插值只替换一次，原始参数中的 `{bytes}` 等字符不递归翻译。

六个备份面板的 schema/枚举校验、来源绑定、generation、单次执行、执行时检查、结果未明处理、丢弃规则和五分钟 TTL 保持原有行为。语言切换不检查或重新核对，不丢弃报告、不延长有效期、不清除确认状态。资料完整性面板没有增加报告 ID、检查时间等基线未展示字段。原先受控通用错误继续使用受控提示，未知私有错误不会因本批迁移而显示。

本批仅迁移 UI，不扩展导出、导入、恢复或删除能力。备份包和快照的原有敏感明文说明完整保留。三个新词典由相应懒加载界面独占，没有加入启动阶段全局词典。

## 分工与工作树保护

主线程负责四类导出面板、共享展示辅助、词典一致性门禁、主题/布局、整合和最终验收。Sol high 独占 RSS 翻译包；两个预检先由 Luna medium 迁移，复核发现报告明细遗漏后停止原作者写入，顺序转交 Sol high 恢复字段并补齐生命周期测试。Sol xhigh 执行独立只读复核和最终全量测试。运行时未提供 Terra，因此判断较多的有界实现使用 Sol high。没有子代理继续委派；写代理的文件范围没有重叠。

开工保存 2341 个源文件哈希和关键文件副本，最终基线缺失为 0。本批涉及 19 个源码/测试文件（11 个已有、8 个新增），另新增本篇记录并更新第八批覆盖矩阵。同期 8 个已有文件修改和 9 个新增文件涉及 P47 的 README、两份比较记录、Rust、契约、Gateway、组件及测试，全部保留。`App.tsx`、`App.navigation.test.ts`、`SettingsCenter.tsx`、`RssReader.tsx`、RSS 独立 CSS、批量队列 helper 和全局 i18n 接线相对开工未变。

本批没有修改 Rust、契约、Gateway 或全局词典接线，没有提交、推送、合并、重置或清理工作树。同期新增的 `KnowledgePackageCheckPanel` 保留在设置中心原位置；设置备份包装容器同时保留这部分并发接线，不将其归为本批 UI 实现。
