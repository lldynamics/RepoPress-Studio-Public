## 已覆盖的核心路径

Linux 已有 Markdown 工作台、Front Matter、写作辅助、受外部变更保护的保存、恢复稿、持久草稿版本与回收站、通用草稿中转、选择性 Git 暂存、计划式提交/拉取/推送、PR/MR、部署查询、Hugo/Zola 预览、资料库与浏览器采集、RSS/Atom 阅读与翻译、AI 编辑/流式对话/加密历史、本机 PDF/OCR、语义检索与确定性内容健康检查。P1–P18 的具体能力和限制见 [Linux README](../README.md)。

“具备核心路径”不等于每个 macOS 模块已经完整移植。尤其不要把 AI 服务档案当作 SiteProfile，把最近仓库当作多站点管理，把基础 Git 操作当作安全同步与冲突处理。

## P19：仓库图片浏览与复用

对照 macOS 的 [图片工作台](../../../Sources/PersonalSitePublisherMac/Views/Images/ImageWorkbenchView.swift)中仓库资源浏览流程，Linux 新增独立图片工作台入口及命令面板入口：

- 显式扫描当前仓库，列出 PNG/JPEG/GIF/WebP，支持路径搜索、格式筛选与名称/体积排序。
- 查看尺寸和体积，按需加载单张图片；扫描或预览可关闭，旧请求不会回填新仓库。
- 编辑 Alt 并复用到当前文章；插入前重读并校验 SHA-256，文章或工作区变化时拒绝应用。
- 公开资源目录沿用现有站点映射，其他图片使用相对于当前文章的路径；修改只进入编辑缓冲区。
- 浏览器演示明确显示不可用。没有可写文章时可以浏览，插入按钮禁用。

读取范围绑定已打开仓库会话；不接受任意绝对路径。扫描跳过构建/依赖目录和符号链接，限制目录项、深度、图片数、读取字节、像素和警告数量；遗漏会显示部分结果。SVG、损坏或无法确认尺寸的图片不进入预览。预览不依赖任意文件协议或外部 URL。

P19 只补齐图片资源浏览与复用，正文引用检查在下述 P22 中补充。**尚未实现** macOS 图片批量压缩、WebP 转换、裁剪、隐私元数据清理、资源删除与回滚、图片 AI 建议；不将这些操作显示为可用。

## P20：本机操作日志

对照 macOS `OperationLogWindowView` 的类别/结果筛选、列表详情及确认清空，新增工作区按钮与命令面板入口，支持动作搜索、当前仓库/未关联仓库筛选和手动刷新。没有打开仓库时也可查看本机记录；浏览器演示明确显示不可用。

- 执行命令结束后记录固定动作和成功/失败结果；计划生成、读取、扫描及轮询不产生日志。成功仅表示该命令返回成功，失败仍可能伴随部分副作用。
- 接入 17 类命令：文稿保存/创建/重命名/删除，历史版本恢复、回收草稿恢复/删除，通用草稿保存/转移/撤销，写作图片导入，Git 索引更新/Git 操作/远程评审，资料文字导入/Markdown 导出/归档导出。
- 只存动作、结果、完成时间、耗时和仓库根 SHA-256 关联键，不存正文、标题、路径、URL、令牌或原始错误。最近最多 500 条；独立 JSON 上限 1 MiB，私有权限和原子替换，异常时保留原文件并明确降级内存模式。
- 日志写入失败不改变原业务返回值。确认清空绑定打开确认时的已加载序号，保留随后完成的新记录；不删除草稿、资料或发布数据。持久化清空失败会报错并保留界面快照。

这批覆盖显式执行命令的本地结果记录，尚未实现 macOS 多来源历史投影、发布台账关联、AI/MCP/RSS/浏览器采集事件、导出或可配置保留期。仓库关联键用于筛选，不是访问授权或不可逆匿名化保证；日志也不是防篡改审计台账。

## P21：已保存站点与受保护切换

对照 macOS `SiteProfile`、`SettingsProfileBar` 与 `PublishingStore+DraftAndSiteActions` 的命名/选择/管理入口，新增独立的持久站点登记和工作区选择器。

- 当前仓库可登记为命名站点；每个规范仓库根仅一项，最多 32 项，稳定 UUID 与注册表 revision 防止旧列表覆盖新修改。
- 列表选中只进入管理；打开、编辑名称、移除登记各有独立动作。移除需确认，保留当前仓库会话、文章、历史与通用草稿，可移除最后一项。
- 选择器始终按实际打开的仓库匹配登记，不提前显示切换成功；只向后端发送 profile ID，每次重新检查目录并创建受限会话。未保存文章需确认，保存/导入期间拒绝切换，过期扫描或期间新增输入不会覆盖当前编辑器。
- 私有 `site-profiles/registry.json` 上限 256 KiB，目录/文件权限为 `0700`/`0600`；损坏、未知字段、路径/文件类型异常或外部存储漂移均拒绝修改，不以易丢失的临时登记伪装保存成功。

这批是命名本地仓库的多站点入口。站点类型及内容路径继续由每次打开时探测，发布/AI 凭据仍沿用已有独立机制；未实现完整 SiteProfile 的模板/资源路径/默认作者与分类、配置复制、站点专属草稿集合及删除撤销。跨站点文章仍走现有通用草稿计划式复制/移动，不自动复制附件或改变 Front Matter。macOS 删除站点及其草稿的语义未搬入本轮登记移除。

## P22：图片引用与 Alt 检查

对照 macOS `RepositoryImageInventoryService` 的引用关联和 `SiteImageWorkbenchService` 的正文引用/Alt 诊断，在现有图片工作台中增加显式的只读检查。

- 复用 `inspect_repository_images` 与 `inspect_content_health_sources`；两份快照绑定同一仓库 session，保持既有 Rust 路径、符号链接与字节限制。Markdown 只扫描 `contentRoot`（没有时扫描仓库），当前编辑缓冲区按路径替换或补入，并标注来源。
- 分析常见内联/引用式 Markdown 图片，屏蔽普通围栏/缩进代码、行内代码、Front Matter 与 HTML 注释；提供文章路径/行号、Alt、原始目标、站点公共目录或文章相对路径的解析结果。
- 区分清单匹配、清单未匹配、外部图片、不安全路径与暂不支持核验。未匹配不代表磁盘不存在；当前范围内未发现引用不等于全站未使用，更不是可删除判断。空 Alt 也可能用于装饰图，需人工判断。
- 支持搜索、状态、空 Alt、当前图片筛选，每页 50 条；匹配项可返回已有 SHA-256 复验的图片预览。未发现引用的图片路径最多展示前 50 条并说明上限。
- Worker 独立运行，可取消、20 秒超时终止，创建/通信失败时拒绝分析，无主线程同步回退。仓库/图片快照/缓冲区变化、关闭时取消并丢弃旧响应。最多 1,000 篇、单篇 4 MiB、合计 32 MiB、2,000 条引用及约 512 Ki 字符输出，超限报告部分结果。

本批检查正文文本，未迁移 macOS 附件模型/封面关联语义，也不是完整 CommonMark、HTML/JSX、wiki 嵌入或站点模板分析。嵌套引用块/列表代码未完整覆盖；不获取网络资源，不运行站点构建，不修改文章或图片。磁盘源与图片清单为逐次读取的快照，外部文件变化需要重新扫描；它们不构成跨文件系统原子快照。

## P23：搜索命中与问题定位

对照最新 main 的 `ContentView` 搜索/问题导航，先接通当前窗口内的受保护文稿定位：

- 点击路径结果打开文稿；点击正文搜索结果保留原始查询、行号和摘要，在已加载的编辑内容中重新核验后选择实际命中文字。使用 Unicode/UTF-16 偏移，支持 CRLF 文稿由后端规范化后的定位；无法核验时提示重新检查，不猜测其他行。
- 同篇定位沿用当前缓冲区；跨文稿切换仍需处理未保存内容确认，取消新跳转不干扰先前已确认的加载。打开期间继续输入、切换仓库/文稿或新的定位请求都会使过期结果失效。
- 写作诊断、内容健康报告与发布中心的当前文稿检查统一走范围定位路径，绑定整份预期正文。只设置选区/滚动/焦点，不借定位写回内容。
- 发布中心增加显式“检查当前文稿”，复用本地 Markdown 写作诊断，最多显示 50 项；编辑、切换文稿或文章目录变化后旧报告失效。此入口不表示完整 SEO、站点构建或远端发布预检。
- 定位等待懒加载编辑器就绪，关闭来源抽屉后再聚焦；旧查询/session 的搜索结果不可点击。

本批没有增加 Rust IPC，也没有扩展原搜索读取范围。正文搜索仍沿用每文稿首个命中；长行摘要只覆盖前 240 个 Unicode 字符，定位另核验查询仍在该行，但不是整文稿磁盘哈希绑定。混合裸 CR 等无法与搜索行号对应的内容会拒绝定位。字段 Inspector 路由、固定大纲和替换预览由下述 P24 补充；多窗口仍待后续。

## P24：属性检查、固定大纲与替换预览

本批由三个互不重叠的实施线程负责字段检查、固定大纲和查找替换；主线程接入真实工作区、协调 P25 共享入口并统一验收。

- “属性 · SEO”生成本地有界报告，覆盖标题、摘要、slug、permalink 和封面路径等常见问题；结果可展开属性面板并定位字段，连续输入保留焦点。报告绑定当前文稿和完整缓冲；编辑或切换后失效。无 Front Matter 时只定位添加入口，不自动创建；结构异常时定位说明。扫描上限为 256 KiB UTF-8，超限明确拒绝，长度提示是编辑建议，不是搜索引擎评分。
- “固定大纲”提供光标所在章节、层级折叠和受保护定位；编辑区域足够宽时置于侧栏，窄时置于编辑器上方。超出展示上限的章节不会误标成最后一个可见章节；不改正文。
- 查找替换默认限定正文，支持冻结非空正文选区；查找导航不改变冻结范围。保留大小写、全词、正则捕获组和单次替换；全部替换先显示完整有界前后文本，再确认写入缓冲。更改正文、文稿身份、查询/选项或只读状态使旧工作失效。
- 查找运算运行于独立 Worker，1.5 秒超时终止，关闭面板或变更输入取消旧请求，失败不回退到主线程正则。整稿上限 512 Ki UTF-16 单元，范围/输出上限 256 Ki，查询 512、替换文本 4 Ki、匹配 2,000 处；超限拒绝本次操作。正文范围无法安全识别时拒绝替换。

本批只修改编辑缓冲区，没有新增文件读写 IPC；不自动保存或联系外部服务。属性面板折叠不代表原始 Front Matter 源码折叠，也不代表完整 SEO、原生多窗口或整个 macOS 编辑器行为已对齐。
