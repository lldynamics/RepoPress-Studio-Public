# P46：资料保存文件的确认式备份包导出

2026-10-03，固定 macOS 比较基线 `2d2858fc5ebc3843d1a281026304c2551741691c`，Linux HEAD `97f1fd75e12b4b9606974890bfa317a7bac9b6e3`。本批未 fetch、合并、提交、推送或导出真实用户资料；先保存 546 个已有修改/未跟踪普通文件及哈希，保留其他 UI 会话工作。

## 用户路径与范围

设置中心“资料保存文件备份包”：选择新的绝对小写 `.json` 路径 → 明确预览 → 知悉并同意敏感资料明文 → 明确一次性导出。打开设置不采集正文，浏览器演示拒绝选择/预览/执行/丢弃原生计划。预览只显示资料项、全部修订和去重正文/归档文件数量、大小、包 SHA-256、目标路径及有效期；不展示标题、来源名称/URL、正文、归档或逐文件列表。

导出包括 schema-v4 清单中的文件夹、保存资料元数据和全部历史修订，以及修订实际引用的 `blobs/<sha256>` 正文和 `archives/<sha256>` 离线网页归档。同类型/摘要共享文件只导出一次；历史旧正文、共享归档均保留。PDF 提取后已保存的正文和 PDF 来源元数据在范围内，PDF 原文件和附件原文件不打开、不打包。Markdown/HTML 中的链接和来源 URL 字符串保留在保存内容/元数据内；外部引用内容不解析、抓取或渲染。

固定排除独立凭据存储、其他工作区来源、仓库当前文件、外部引用内容、未引用文件、持久完成操作回执、运行时状态、PDF 原文件及附件原文件。已保存正文、标题、来源名称/URL和偏好仍可能含秘密，不自动脱敏。包内 base64 是可逆明文编码，不是加密。保存的本地索引/远程 AI 偏好只是元数据，本批没有恢复或激活权限。

## 严格采集与格式

只接受当前清单版本 4；旧版和未来版拒绝，不迁移或修复。复用 P45 的纯引用投影：校验 item/folder ID、标题/来源、历史修订和最新项一致性、摘要/大小/格式、分类引用、重复摘要声明冲突及既有库容量。P46 另对被排除的持久操作回执进行纯结构、已知字段、唯一 ID 和既有语义校验，包括时间、指纹、动作、归档类型与分类；通过后导出清单的 `completedOperations` 固定清空，不恢复业务状态、不清理源账本。P45 预检行为不变，报告不是导出计划。

任何引用缺失、损坏、非 UTF-8 正文、归档格式不符、不安全文件、归档记录缺失资源/截断/完整性未知或超限，都拒绝生成包计划，不省略内容后宣布完整。合法空清单可导出空库；缺失清单不等同空库。

| 包字段 | 约定 |
| --- | --- |
| `format / schemaVersion` | `repopress-knowledge-saved-files / 1`，独立 Linux 格式 |
| `sourceManifestSchemaVersion / scope` | `4 / applicationSavedKnowledge` |
| `manifest` | 验证后的 folders/items/revisions；完成操作回执为 `[]` |
| `manifestSha256` | 紧凑 JSON 序列化的导出清单 SHA；不等于原清单原始字节 SHA |
| `sourceManifestSha256` | 原清单原始字节 SHA，用于记录采集来源，未包含回执内容 |
| `files[]` | 唯一 `blobs/<lowercase sha>` / `archives/<lowercase sha>` 路径、类型、大小、SHA、`encoding=base64` 和数据 |
| `allSavedReferencesIncluded` | 只表示包内闭合全部保存清单引用；不证明网页外部资源完整 |
| `consistentSnapshot / externalReferencesIncluded` | 固定 `false / false` |
| 凭据存储/完成回执包含标记 | 固定 `false`；敏感资料内容仍需明文同意 |

上限：清单 2 MiB，1024 个唯一资源，资源合计 32 MiB，正文单个 5 MiB、归档单个 24 MiB，JSON 包 48 MiB。每轮来源读取与最后复验检查五秒预算；单个底层文件系统调用无法被抢占，包编码/写盘时间不含在该读取预算内。持久库本身允许的容量更大，本批不会为了塞入包而裁剪。

## 文件安全与一次性执行

独立固定应用根 descriptor；不调用资料初始化、加载迁移、垃圾清理或条目导出辅助路径。资料目录、正文目录和归档目录必须当前用户所有、0700；文件必须当前用户所有、0600、普通单硬链接。以 `O_PATH | O_NOFOLLOW` 分类，再通过已核对的 `/proc/self/fd` inode 内容读取，FIFO/设备/符号链接不会在分类前打开。读取分块受预算限制，每个文件核对长度、摘要/格式、descriptor 和命名空间的 inode/权限/链接数/mtime/ctime；采集后再次核对全部来源及目录。

采集冻结包内容与文件集，在内存保存最多两份五分钟计划。执行开始即消费计划，包括未同意、过期、来源漂移或目标失败；不会自动重试。执行前、临时文件最终提交前和发布后重新读取全部来源并核对原始清单 SHA、内容摘要、目录/文件身份与时间，排除内容的回执变化同样使计划失效。逐文件观察仍非跨文件原子快照，相关标记固定 false。

目标必须位于应用根外，父目录存在、当前用户所有且不可被组/其他用户写入；拒绝路径别名、`..`、目标已存在和已初始化 Git/bare/worktree 目录及其子目录。复用既有 `Destination` anchored-parent descriptor 写入，只新增该格式的 48 MiB 容量构造；私有 0600 临时文件、同步、读回核验、最终来源/目标复验、`persist_noclobber`、目录同步和文件身份/内容核验。目标竞争出现不覆盖任何文件。最终发布后若来源或目标改变，返回结果未明，保留可能已存在的私有冻结副本，不自行删除、重试或改源。

界面在关闭/禁用/刷新/gateway 变化、卸载、到期、更换路径、重新预览或取消时撤销计划和同意；可识别 UUID 的迟到/无效计划交回原 gateway 丢弃。同步 busy/plan/context/consent 绑定阻止双击和旧 DOM 执行。收据 ID、路径、大小和 SHA 必须与被消费计划一致才显示成功。
