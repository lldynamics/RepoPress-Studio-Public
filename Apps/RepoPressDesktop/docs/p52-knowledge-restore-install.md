# P52 资料库安装事务与显式恢复

2026-10-07。本批把 P51 的合并清单接入确认式磁盘安装。用户选择已验证的私有候选、生成安装计划、确认导入权限关闭与写入当前库后，才执行安装；保留当前所有资料、历史、分类和权限，候选新增项的 AI/语义索引权限关闭，completedOperations 清空。嵌套 P51 报告依旧表示只读内存证据，不能单独授权安装。

## 安装与持久化

计划最多两份、五分钟，绑定当前/候选全部资源与 inode/stamp、身份策略和合并哈希，wall-clock/monotonic 双重检查；先消费计划再检查确认，拒绝、失败、过期、重复调用均需重新准备。安装前重新捕获真实内容；内容只保存在本次私有调用中，不进入 IPC、日志或内存计划。

当前保存树必须恰好包含 manifest.json、blobs、archives 和全部去重历史引用；遇到未知节点、未引用文件、软/硬链接、FIFO、非私有权限、资源不完整、超限或任何漂移时拒绝。候选沿用 P49/P50 严格私有布局与内容核验。每侧 1,024 个资源、32 MiB，合并最多 2,048 个资源、64 MiB、清单 2 MiB、2,000 项与 128 个分类。单次捕获五秒，阶段复制检查三十秒预算；预算在 I/O 检查点执行，不承诺中断内核阻塞调用。

取得应用根目录 flock 后，先以私有文件持久化 knowledge-restore-intent.json 的 preparing 意图，再创建 UUID 命名的私有暂存库，复制引用字节，禁止硬链接。文件 0600、目录 0700，全部文件/目录和应用根依次 fsync，读回核验后持久化 intent。最终再次核验来源、当前库、暂存库、期限与应用根身份，再以 descriptor-relative renameat2(RENAME_EXCHANGE) 原子交换 knowledge-v1 与暂存库，fsync 根目录，核验两棵树后写 committed 标记。原库留在事务目录。目标文件系统必须支持原子 exchange；失败会保留现场，不自动删除或回滚。

顶层目录交换改变 ctime，因此恢复证据绑定其 dev/inode/mode/uid；子目录和所有文件仍绑定完整 stamp、哈希和闭合清单。应用根支持当前用户所有且无 group/other 写入、无特殊权限位的既有目录；根目录身份在 store 生命周期内固定并持续复验。普通 I/O 通过已持有根目录 fd 定位；所有公开资料库操作前后核验根/库/子目录身份与私有权限，缓存 generation 包含子目录身份与清单 stamp。既有资料目录权限变化时拒绝，不自动 chmod 修复。此锁协调支持该协议的本地应用实例，不能阻止其他同 UID 程序任意改写用户文件。外部程序在进程重启前将整个应用根移走并隐藏其中事务记录时，新进程无法从替换后的路径发现已移走的记录；本批没有额外建立父目录级恢复台账。

## 中断恢复

检查恢复状态是手动只读操作。诊断不授权写入，每个完成、回滚或取消操作都须另行生成短期、一次性恢复计划，确认后再次比较完整观察。

| 诊断 | 当前树与保留树 | 允许操作 | 普通资料库访问 |
| --- | --- | --- | --- |
| none | 无事务记录/保留节点 | 无 | 可用 |
| preparing | 当前原库未变，暂存尚未完整核验 | 取消准备 | 阻止 |
| prepared | 当前原库，暂存新库完整 | 取消准备 | 阻止 |
| installed | 当前新库，保留原库，intent 未结束 | 完成或回滚 | 阻止 |
| committed | 当前新库与保留原库均未变 | 回滚 | 可用 |
| rolledBack | 当前原库与保留新库均未变 | 无 | 可用 |
| cancelled | 当前原库与已准备文件保留 | 无 | 可用 |
| changed | 观察发生变化 | 无 | 未决事务阻止；终态仅允许已绑定的当前根 |
| invalid / unavailable | 记录损坏、路径/权限异常、锁忙或根不可用 | 无 | 阻止 |

取消只写终态，保留部分暂存，不删除文件；因此 preparing 的 snapshotRetained 为 false，不能声称完整回滚快照。回滚前将 committed 改为持久 intent，再执行反向交换，避免反向交换后仍留 committed 标记。反向交换后的中断可诊断为 prepared，并显式取消准备以保留原库。失败或未知回执提示可能已写入文件，须检查状态，不自动重试。

启动时遇到未决或无效事务，资料库以阻止状态构造；不迁移、初始化、读取损坏库或垃圾回收，恢复接口仍可用，浏览器采集服务不启动。正常资料库操作也使用同一根锁，检测清单 stamp/库根 generation 变化并重载持久状态，同时清除旧导出计划与打开请求，防止旧缓存覆盖恢复结果。终态后正常编辑允许；任何变化会取消回滚资格。

## 容量与边界

只保留一个持久事务，包括 committed、rolledBack 和 cancelled；新安装会拒绝。保留快照含私密明文，未增加自动清理、删除、容量回收或历史修复。P53 建议补显式容量释放与已知终态快照管理，并分别验证清理授权。

本批只实现已保存资料库的有界本地安装；来源真实性、外部附件、配置/RSS/草稿等多库原子交换、整工作区恢复仍待实施。没有对用户真实资料库执行安装。原生 WebView/文件选择器、GNOME/KDE Wayland/X11、真实断电/文件系统故障、发行包和线上 CI 不包含在本次本地验收。
