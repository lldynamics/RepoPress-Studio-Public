# P48：显式私有资料候选目录

日期：2026-10-03。沿用 macOS 对照基线 `2d2858fc5ebc3843d1a281026304c2551741691c`；本地 HEAD `97f1fd75e12b4b9606974890bfa317a7bac9b6e3` 未变化。

## 实施范围

接续 [P47 独立包校验](p47-knowledge-package-check.md)，设置中心增加“选择资料 JSON 文件 → 选择候选父文件夹 → 生成候选预览 → 明确同意敏感明文复制 → 一次性创建并核验”。预览只读，返回来源、生成的候选路径、计数、大小、摘要和五分钟有效期。浏览器演示的五个入口全部拒绝调用。

执行只向用户选择的父目录中新建 `repopress-knowledge-stage-<planId>`，不初始化、迁移、GC、激活、安装或替换当前资料库。候选保留标题、来源 URL、分类、偏好和已保存正文/归档等敏感明文；报告和结果不返回这些内容。`candidateOnly=true`、`currentLibraryChanged=false`、`restoreReady=false` 固定，成功提示也明确尚未获得可恢复副本。

macOS 的 `WorkspaceBackupService+Restore.swift` 还有暂存、工作台/RSS/附件转换、旧数据替换、事务记录、失败回滚和中断恢复；本批只补 Linux 保存资料范围的独立磁盘候选，不代表这些行为已对等。

## 来源、预览和执行合同

直接复用 P47 严格包解析器：格式/版本和精确字段、递归重复键拒绝、清单投影、全部保存引用闭合、canonical base64、大小和 SHA-256 校验。原始清单摘要只能核对语法，固定 `sourceManifestHashVerified=false`；`consistentSnapshot=false`，不承诺保存归档内部附件或外部引用语义闭合。

来源必须是显式绝对 JSON 路径、当前用户所有、0600、regular、单硬链接；用持有描述符核对路径/inode、权限、mtime/ctime、长度和摘要。目标父目录必须已存在、当前用户所有、组/其他用户不可写且无特殊权限位；拒绝符号链接、路径别名、应用根目录内位置及已初始化 Git/bare/worktree 的祖先。父路径最长 UTF-8 4000 字节，生成候选路径最长 4096 字节。

每个 store 串行执行有界解析与复制，最多保存两个计划。计划只持有来源/目标描述符、身份、统计和摘要，不保留解码明文。五分钟墙钟与单调期限同时检查；开始执行先消费计划，拒绝同意、失效、漂移或失败均不能重用 ID，取消幂等。执行重新读取来源并重做严格解析，比较包摘要与确定性候选清单；写入完毕再完整读取来源并比较摘要。

读取/解析沿用 P47 的 48 MiB 包、2 MiB 清单、1024 个/32 MiB 唯一资源、131072 个 JSON 节点和 5 秒合作式预算。候选最多 1026 个文件、`34 MiB + 4096` 字节，整体执行使用同一个 30 秒合作式期限；文件系统调用不能被这个期限抢占。

## 磁盘布局与失败边界

候选目录包含最后写入的 `candidate.json`、净化后的 `knowledge-v1/manifest.json`，以及 `knowledge-v1/blobs/<sha>` 和 `knowledge-v1/archives/<sha>`。所有目录精确 0700，文件精确 0600、当前用户所有、regular、单链接。标识文件仅记录固定格式/版本、计划及来源包/清单摘要和排除标志；不包含资料标题、正文、来源 URL 或原始清单摘要。

通过固定父目录描述符 `mkdirat` 排他创建新目录，以 `O_DIRECTORY|O_NOFOLLOW` 打开并核对私有、空目录和身份；固定文件以 `O_EXCL|O_NOFOLLOW` 创建，逐文件同步。来源、应用根目录、父目录、候选及子目录身份在写入边界重复核对。资源和清单读回验证内容、SHA、权限、身份和精确目录项后，才再次检查总期限和上下文并写入标识；标识之后和返回之前再次核验全部内容。候选清单摘要绑定按路径排序的 `{path,byteSize,sha256}` 列表，包含标识文件自身。

创建是逐文件直接复制，不是原子发布或恢复事务。mkdir 与打开新目录之间没有“创建并返回目录 FD”的原子系统调用；上述检查降低竞态影响，但不提供同 UID 恶意进程完全隔离的保证。任何创建开始后的异常、超时、篡改或任务失败，都返回“结果未明”：私有部分目录可能留下，保留已知候选路径，禁止自动重试、自动删除、覆盖或清理。标识存在也不授权未来恢复；返回后候选仍可能被改动，必须在后续阶段独立重新校验。

## 界面与接线

独立 StageGateway 提供两个选择器、计划、执行和取消；合同、原生/演示 gateway、Rust core/commands、AppState 和 Tauri 注册同步接入。共享设置区仅增加面板挂载，保留其他会话的布局改动。

面板核对顶层精确字段、固定预算/标志、数量关系、生成路径、摘要、有效期，以及嵌套报告与计划的 ID/时间关联。明文同意绑定当前计划、原始 gateway、来源/父路径和启用/刷新上下文；同步 refs 阻止双击、旧 DOM 同意/执行和迟到计划越界。换源、换父目录、重新预览、取消、失效、卸载或上下文变化均清除同意。错误只展示固定提示及已审阅的候选路径，不回显后端异常内容。
