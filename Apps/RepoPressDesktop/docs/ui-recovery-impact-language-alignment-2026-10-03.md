# 工作台 UI 对齐：第六批

日期：2026-10-03。承接[第五批发布工作台](ui-publishing-language-alignment-2026-10-03.md)，沿用[第一批](ui-workbench-alignment-2026-10-02.md)固定的 macOS 参考。本批完成发布台账、回滚检查与恢复计划、私有回滚证据归档、恢复历史和文章下线影响审阅的简中/English 文案迁移。本批没有刷新 macOS 比较基线，不宣称最新实机像素一致。

## 已实现

- 发布台账的来源、状态、分页、部分来源提示、容量诊断、未决目标和恢复摘要支持双语；开始、核实及历史观察时间按界面语言显示。
- 回滚条件审阅、单提交逆向变更预览、候选计划、恢复事务和本地恢复历史支持双语。受控 blocker、warning、issue、action、verification 和 outcome 枚举在展示时翻译，历史观察与当前状态继续分别说明。
- 私有回滚证据归档的目的地选择、计划、大小、有效期、明文内容说明、知情勾选、确认、取消、成功和结果未明提示支持双语。
- 文章下线影响审阅的摘要、筛选、分页、局部结果说明、来源重查和定位控件支持双语；本地分析生成的理由与警告带独立展示描述，后台分析的已知本地错误使用显式标记。
- ARIA 标签、进行中状态和本地错误随语言更新；英文长文案在已有发布抽屉布局内换行，浅色和深色主题均可读。本批无需修改 `App.css` 或工作台导航。

## 行为与数据边界

语言仅参与展示。切换语言不重新读取台账、生成计划、访问远端或创建 Worker，不重置分页、筛选、同意勾选或冻结证据，也不延长原定有效期。Gateway/session/revision 身份校验、generation 过期响应保护、单次执行、取消与 discard 保持原有逻辑。

URL、分支、路径、标题、ID、SHA、补丁和保存的源文本保持原文；后端的未知 warning、summary 和原始错误继续按既有规则展示或遮蔽，不依据文字与字典相同就推断它是本地 UI 消息。参数只插值一次，用户数据中的模板字样不会再次解析。

下线影响报告保留原有 `reason`、`warnings` 和生成时的源文本。本地 analyzer 附加可选的展示描述，组件只在描述的 `source` 与对应原文完全相同且没有参数时翻译。未标记的旧报告、描述错配和带参数的未知描述显示原文。Worker 错误只在已知 code 和对应消息同时匹配时作为本地消息；未标记的同名消息和未知错误保持原文。

扫描预算、引用分类、部分或遗漏提示、零命中边界、快照漂移失效和按生成时原文精确定位保持不变。报告仍是只读审阅，不授予删除、远端下架或网站路由变更权限。归档仍是原有的明文导出计划，不授予恢复或发布权限。

## 分工与工作树保护

主线程负责发布台账、恢复事务/历史、下线影响面板及本地展示契约、共享字典接线、整合和最终验收。Sol high 独占三个回滚检查组件、字典与专项测试；Luna medium 独占归档组件、字典与专项测试，完成后顺序补充恢复事务/历史专项测试；Sol xhigh 独立只读复核。运行时没有 Terra，判断较多的有界包使用 Sol high。子代理没有继续委派，也没有两个写代理共同拥有同一文件。

开工保存 2290 个源文件哈希和关键文件副本；最终基线缺失文件为 0。并发出现的 RSS/草稿数据库快照、备份设置、契约、Gateway、Rust 及相关文档变化保留，不归因为本批实现。`App.css` 与 `App.navigation.test.ts` 相对本批开工基线未变。没有提交、推送、合并、重置或清理工作树。
