# 工作台 UI 对齐：第十五批

日期：2026-10-07。承接[第十四批草稿生命周期](ui-draft-lifecycle-alignment-2026-10-07.md)，补齐历史比较的目标选择与分区层次。参考当前检出的 `Sources/PersonalSitePublisherMac/Views/Editor/DraftVersionComparisonView.swift`；没有刷新远端或最新 Mac 实机视觉基线。

## 已实现

- 左侧所选版本作为比较来源；右侧可选择当前编辑缓冲区或另一历史版本，排除来源本身。当前稿与历史目标具有不同的差异标题。版本选项保留日期和 SHA 片段，原始 ID 通过独立前缀与“当前稿”选项区分。
- 比较区显示全文增删统计，再分别显示 Front Matter 原文差异和正文差异。上下文、增删符号、未知字段、注释、多行写法及原始数据都保留，新增/删除行同时使用符号与主题颜色区分。两个分区具有独立标题和 ARIA；标题、选择器及原文容器支持换行。
- 切换语言保持目标、节点与焦点，不重新读取版本，也不执行恢复。当前稿目标随未保存文本更新；历史目标继续比较固定的历史快照。恢复按钮及提示明确指向左侧所选来源，目标选择不改变恢复版本或 baseline SHA。
- 恢复后即使列表仍保留相同的所选 ID，也会重新读取来源详情，避免刷新清空详情后比较区一直显示加载状态。

## 比较边界

先对两份全文调用已有 `compareDraftVersion`，沿用 400 行和 128 KiB UTF-8 上限。超限时只显示既有统计和提示，不再计算分区 LCS，也不因拆分绕过全文预算。有限范围内的比较仍是同步计算。

分区仅识别首行的 YAML `---` 或 TOML `+++` 与对应结束分隔符，支持 BOM、分隔符周围空白、LF/CRLF/单独 CR；YAML `...` 也可结束分区。Front Matter 保留开始分隔符、BOM 和结束行的换行，正文从下一个原始字符开始，不修剪分隔空行，不解析、解码或丢弃字段。任一开始分区未闭合时显示说明，退回原有全文差异；两份文稿均无 Front Matter 时保留完整正文比较。

这是按分隔符识别的原文分区，不判断 YAML/TOML 是否语法有效，也不把原文字段变化描述为 Mac 的字段语义变化。传入比较器的文本切片保持原始字符内容；既有行差异仍会规范化换行符，行号在各分区内计数。本批没有改写文章内容。

## 上下文与恢复保护

版本列表、来源详情和目标详情绑定 session、仓库根、文章 ID/路径、SHA/revision 及版本 ID；目标请求还绑定来源版本。在 effect 执行前，呈现逻辑就拒绝旧上下文的列表/快照。更换来源、目标、文档、仓库、标签页、关闭或卸载会失效相关请求，过期成功或错误均不能覆盖新比较。

来源与目标变成同一版本、或目标已不在当前列表时，立即回退到当前稿。网关错误保留原文及来源标记，空错误仍不生成错误 alert；本地回退只翻译受控说明。新增列表上下文守卫防止用旧列表选择在新文章上下文发起恢复。恢复、回收恢复、永久删除函数的实际 IPC 参数、返回对象、来源回调、dirty/只读/busy 限制和确认流程保留原有合同。
