## 已实现与导出范围

设置中心保留 P41，并增加“配置备份导出”。默认只选工作区配置；用户可另选站点登记与 AI 服务档案。选择新的 JSON 路径后，明确点击预览，再为当前计划勾选敏感明文同意，最后明确一次性导出。打开设置和选择路径不会读取配置或生成计划，取消路径不会写文件。

| 配置 | 已保存文件 | 输入上限 | 预览摘要 |
| --- | --- | --- | --- |
| 工作区 | `workspace/workspace-state.json` | 5 MiB | 一份状态配置、是否包含持久恢复稿 |
| 站点登记 | `site-profiles/registry.json` | 256 KiB | 合法站点记录数，最多 32 |
| AI 服务档案 | `ai-provider-profiles-v1/profiles.json` | 128 KiB | 合法服务档案数，最多 16 |

预览在本机读取所选持久文件，但只返回类别、计数、原文件字节数、目的地、归档大小/SHA-256 与到期时间，不将正文、站点名称/路径、AI 端点或模型送入面板。缺失文件、损坏结构、未知版本/字段、警告降级或不安全存储都拒绝生成计划；合法空 profiles 与缺失存储严格区分，不复制内存默认状态，也不输出部分备份。

工作区文件原加载器会忽略未知字段或容错为默认状态。P42 直接读取白名单文件，额外拒绝未知顶层/偏好/最近仓库/恢复稿字段，再使用现有完整状态校验；重复已知 JSON 字段也拒绝。站点和 AI 档案复用原有严格结构及业务校验，只新增纯校验入口，不调用存储初始化、迁移或修改方法。

配置可能包含最近仓库和文章位置、恢复稿全文及基线、私有站点名称/仓库路径、AI 端点/模型和时间。它们以明文写出，字段值、正文与 URL 本身可能含秘密；不会自动脱敏或加密。独立凭据/系统钥匙环、加密聊天、发布恢复台账、操作日志、仓库文件、外部附件、运行时和未知位置全部排除。资料库、RSS、通用草稿与草稿历史也排除；尚未保存的设置/编辑缓冲区不属于此备份。

## 格式与计划边界

归档 `format = repopress-workspace-config`、`schemaVersion = 1`，保存捕获时间、所选类别、固定排除项，以及 `configurations` 中每类配置的结构数据和 `dataSha256`。分片校验和针对规范序列化后的 `data`；整个文件 SHA-256 与大小在计划和回执中核对。结构数据保留，空白和键排列不承诺保留，因此输入文件长度之和不等于归档长度。

计划声明 `structureVerified = true`、`consistentSnapshot = false`、`includesCredentials = false`。结构已校验不证明跨来源原子快照、当前运行态一致、内容无秘密或整工作区可恢复；校验和不认证备份来源。此格式不是 macOS 工作区备份/交换格式，当前未提供导入或恢复命令。

每份计划最多 8 MiB，绑定选中范围、冻结数据、文件/目录身份及元数据、目的地目录，五分钟有效，全应用最多八份。更改范围/路径、取消、关闭/禁用、刷新或更换 gateway 会清除计划与同意，迟到预览由原 gateway 丢弃。执行处理器同步检查当前 plan/context/consent 引用和到期时间，防止 React 重渲染前旧 handler 使用已撤销同意。

执行先消耗 ID，再检查明文确认、到期、全部选中来源及目的地；写入提交前和提交后再次复验。P41 的只读清单 ID 与本批执行计划完全独立。失败不自动重试、不沿用旧同意、不覆盖或清理已有文件；提交后最终复验失败可能已有文件，界面明确提示查验后再选择新名称。

## 文件系统与副作用

- 来源由应用固定私有根描述符定位，经逐组件 `O_PATH | O_NOFOLLOW` 检查目录/主文件后，使用 `O_RDONLY | O_NOFOLLOW | O_NONBLOCK` 有界读取。只接受当前用户的 `0700` 目录、`0600` 普通单硬链接文件。根目录身份变化、读取期间/执行前的文件替换、权限或字节漂移均拒绝。
- 目的地必须是新 `.json` 文件，父目录已存在、属于当前用户、不可被其他用户写入；拒绝符号链接路径、应用数据目录内路径及发现 Git 元数据/裸库结构的目录。只检查 Git 标记元数据，不读 gitdir 内容或执行 Git。空 `.git` 目录不作为已初始化仓库，后续新增有效标记会使计划失效。
- 复用 P40 已验证的目的地写入原语，除模块内可见性外保留原行为：绑定父目录描述符，私有临时文件写入、fsync、读回，随后不可覆盖发布新名称、同步目录并核验最终身份/权限/硬链接数/完整字节。P40 事务行为保持原边界。
- 不修改来源配置，不查询凭据，不读数据库、不 checkpoint、不清理资料、不解密聊天、不运行仓库脚本、不调用远端。读取配置属于显式本机操作，可能更新系统访问时间；不声称本批仍只有元数据访问。
- 三个 IPC 命令为 `plan_workspace_config_backup`、`execute_workspace_config_backup`、`discard_workspace_config_backup`；保存路径选择使用已有原生 dialog。浏览器演示四项操作均拒绝。
