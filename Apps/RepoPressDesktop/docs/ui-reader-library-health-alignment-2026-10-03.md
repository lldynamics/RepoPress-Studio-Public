# 工作台 UI 对齐：第八批

日期：2026-10-03。承接[第七批智能工具](ui-ai-tools-language-alignment-2026-10-03.md)，沿用[第一批](ui-workbench-alignment-2026-10-02.md)固定的 macOS 参考。本批完成 RSS 主阅读器、资料库和仓库内容健康面板的简中/English 迁移，并修正浏览器验收中发现的阅读布局问题。没有刷新 macOS 比较基线，不宣称最新实机像素一致。

## 已实现

- RSS 订阅侧栏、范围、文章列表、过滤与排序、阅读控件、高亮笔记、受控翻译展示状态、OPML/备份/偏好窗口、确认与撤销提示支持双语。日期、数量和缓存大小按当前语言显示。嵌套翻译面板在本批未迁移，后续已由[第九批](ui-rss-translation-backup-alignment-2026-10-03.md)补齐。
- 资料库的搜索、分类、明确文字导入、资料详情、阅读进度、历史版本、离线归档、Markdown/归档导出计划和扩展配对界面支持双语。日期、修订数量和大小随语言显示；SHA-256 仍使用原有 `<code>` 展示。
- 内容健康的扫描边界、等待/失败、报告、完整性、过滤、截断、遗漏和定位控件支持双语。本地受控诊断通过展示元数据翻译，保留原始报告字段；旧报告或不匹配的元数据回退显示原文。
- RSS 工作台、提示、模态窗口及“系统”阅读主题采用已有语义颜色。暖纸、纯白和暗色阅读选择继续使用原有独立主题。
- 浏览器发现正文被后续笔记与翻译区压缩至约 33px。本批让阅读列整体可滚动、直接子项不收缩，正文保留原滚动元素、至少 12rem 高度及 65vh 上限；没有改动阅读进度计算。940px 窗口的标签输入溢出已修正。375px 窗口的智能工具标签使用三列、两行布局，减少英文单词断行。

## 行为与数据边界

语言只影响展示，不进入加载或扫描 effect 的依赖。切换语言不重新请求文章、全文、资料或历史，不取消等待中的 Worker，不清空过滤、选中条目、输入、偏好、阅读样式、修订预览或导出计划。确认使用点击时的语言；请求身份、generation、冻结计划和单次执行保护保持原有行为。

RSS 原始订阅名、文章、作者、标签、URL、Feed issue、全文失败信息和 Gateway 提示保持原文。空原始消息继续清除旧提示，不生成空提示框；原有未知错误 fallback 规则保持不变。

资料标题、来源、正文、分类名、片段、端点、令牌、SHA、后端状态、计划摘要与警告保持原文。资料库错误继续使用原有路径识别规则遮蔽本地路径，但遮罩改为结构化片段：仅生成的遮罩随语言变化，错误中原有 `[本地文件]`、私有字符或模板字样不被误替换。本地延迟通知保留来源模板和原始参数，按当前语言重新展示。

内容健康的筛选仍匹配报告原始标题、说明、路径和代码；翻译显示不改变查询语义。定位继续使用扫描开始时冻结的编辑器覆盖文本及范围。源扫描 warning/omission 和未标记的 Worker/Gateway 错误保持原文；只有标记的受控本地失败翻译。报告缺少展示元数据时不猜测来源。

三个新词典由各懒加载界面独占，`useI18n` 支持稳定的局部词典和共享标签回退。新词典没有加入启动阶段的全局词典数组；插值为一次替换，不重新解析原始参数中的模板字样。

## 分工与工作树保护

主线程负责共享翻译接线、内容健康展示元数据、主题与布局、整合及最终验收。Sol high 独占 RSS 组件、词典和测试；资料库先由 Luna medium 完成基础迁移，经只读复核发现遗漏后，顺序转交 Sol high 补齐界面和生命周期测试，原作者停止写入。Sol xhigh 执行独立只读复核和最终全量测试。运行时没有 Terra，判断较多的有界实现使用 Sol high。子代理没有继续委派，写代理文件范围没有重叠。

开工保存 2324 个源文件哈希和 11 个关键文件副本，最终基线缺失为 0。本批共改动/新增 14 个源码文件；`App.tsx`、`App.navigation.test.ts`、RSS 独立 CSS 和内容健康独立 CSS 相对开工未变。同期 11 个已有文件的修改涉及 README、两份比较文档、契约、Gateway、备份组件及 Rust，全部保留，不归因为本批 UI 实现；最终前端 gate 包含这些并发模块及其新增测试。本批没有改动 Rust、契约或 Gateway，没有提交、推送、合并、重置或清理工作树。
