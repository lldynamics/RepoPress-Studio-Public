## 实施范围

接续 [P48 私有磁盘候选](p48-knowledge-package-stage.md)，设置中心增加显式目录选择、候选独立检查、当前保存清单的身份/元数据冲突计数、五分钟一次性重新核对和取消。检查不依赖 P48 旧计划或进程内成功结果。浏览器演示四入口全部拒绝，不模拟核验成功。

本批全部只读：不创建目录，不修复权限，不初始化、加载迁移、GC、清理、激活或替换任何资料库。只显示所选路径、数量、大小、摘要、固定状态和边界，不返回标题、正文、来源 URL、完整清单或身份列表。

候选内容通过检查仅表示当前观察到的私有布局、保存引用和内容匹配。标识文件中的来源包摘要只能验证语法，无法用候选重新得到原始 JSON 包；标识也未签名，不能证明由可信进程生成。`sourcePackageHashVerified=false`、`candidateAuthenticityVerified=false`、`consistentSnapshot=false`、`filesystemWrites=false`、`currentLibraryChanged=false`、`restoreReady=false` 固定。

## 候选协议与文件边界

仅接受绝对、最长 UTF-8 4096 字节、无空/点/父分量或符号链接别名的路径，末级名称必须为 `repopress-knowledge-stage-<lowercase UUID v4>`，并与标识 planId 完全一致。候选必须在应用根目录外，父目录已存在、当前用户所有、组/其他用户不可写且无特殊权限位；拒绝已初始化 Git/bare/worktree 祖先。

目录必须精确 0700，文件精确 0600、当前用户所有、regular、单硬链接。根目录只有 `candidate.json` 和 `knowledge-v1`；后者只有 manifest、blobs、archives，正文/归档目录项与清单投影的唯一引用集合精确一致。未知字段/版本、尾随 JSON、任意对象深度重复键、假恢复/凭据标志、标识缺失、额外/遗漏资源均拒绝；不清理 P48 的部分目录。

候选清单必须为 P48 保存的紧凑 canonical Value 序列化，与标识摘要匹配，completedOperations 必须为空；调用纯引用投影验证分类、身份、全部历史修订和引用，不经过资料库的加载/迁移入口。资源仅使用生成的固定前缀及小写内容地址，逐个验证声明大小、UTF-8/归档格式和 SHA-256，拒绝保存归档已声明缺失、截断或未知完整性。仍不证明归档内部附件/外部引用闭合。

来源目录和每个文件通过 nofollow descriptor 遍历。O_PATH 先判定类型，FIFO、设备或链接不作为内容打开；读取已核对 inode，比较前后权限、链接数、长度、mtime/ctime及当前名字。候选文件与当前清单保留 O_PATH witness 到最终验证，同时比较 held inode 与 descriptor-relative 名称；目录身份/完整 stamp 和所有文件 witness 在比较及 DTO 构建后再次复验。摘要按排序的路径、大小、内容摘要列表计算，包含标识文件；重新核对指纹还包含目录/文件 stamp 和应用根身份，因此字节相同的 inode 替换也算变化。

上限：候选 1026 个文件、34 MiB + 4096 字节；标识 4096 字节；清单 2 MiB；资源 1024 个/32 MiB；递归 JSON 131072 节点；全次检查统一 5 秒合作式预算。调用原 P47 严格 JSON visitor 的纯抽取入口，保留其行为和默认递归深度保护。时间检查不能抢占单个系统调用；超限或不能安全读取会明确失败，不降级为成功。

## 当前库与冲突含义

只读现有应用根下 knowledge-v1/manifest.json，执行版本、全部字段、分类/资料/历史引用和完成回执的纯验证，但不检查当前正文或归档文件。`currentLibraryResourcesVerified=false` 固定，当前状态“已核验”仅指清单；即使当前资源缺失，本批也不能声称可恢复或可替换。

当前清单未能核验时返回 missing/unsafe/unreadable/invalid/changed；当前计数、摘要和 conflicts 均为 null，不将危险或缺失库伪装成空库。检查过程中目录、清单 inode/权限/内容发生变化，状态为 changed，冲突预览被清空。不会创建缺失的当前库。

可比较时按 itemId 或 folderId 分组，完整保存 Value 相同算 identical，同 ID 的元数据、偏好或历史不同算 changed；双方各自缺少另一侧 ID 算 candidateOnly/currentOnly。共八项资料/文件夹计数，分别严格闭合两侧总数。标题相同不构成身份相同；不选择覆盖、合并、跳过策略，不建议删掉当前独有项，不执行导入，也不自动应用候选的远程 AI/语义索引偏好。当前完成回执不参与身份比较或恢复，但其变更会改变当前清单摘要。

## 报告、重新核对和接线

最多保存两个进程内报告，只保存路径、观察指纹、有效期和可比较状态，不保留明文或文件描述符。五分钟墙钟与单调期限同时检查；重新核对先消费旧 ID，过期/失败不能重用，取消幂等。重新核对从所选路径重新打开、完整重做候选和当前清单观察，产生新 ID；双方当前清单均可比较才可能返回 unchanged 或 changed，否则 inconclusive。unchanged 仍不证明当前资源、来源包真实性或恢复资格。

界面核对精确 DTO 字段、固定预算/标志、路径/标识/时间关联、计数关系和冲突分区；绑定原 gateway、启用/禁用/刷新上下文、路径及渲染闭包，同步 refs 阻止旧 DOM、双击、迟到和过期请求越界。换源、重新检查、取消、失效或卸载丢弃报告，迟到/无效但可识别的报告 ID 交回原 gateway；错误只显示固定提示。原生 Gateway、浏览器拒绝实现、合同、Rust core/commands、AppState、Tauri 注册和共享设置挂载同步更新。

macOS 的恢复服务已有工作台/RSS/附件转换、安装事务、替换与中断回滚；本批只补候选观察和清单冲突证据，不能替代这些恢复能力。
