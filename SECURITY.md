# Security Policy

## Reporting a vulnerability

Please do not open a public issue for a suspected vulnerability, secret,
private path, or user-data exposure.

Use GitHub private vulnerability reporting when it is available for this
repository. If that channel is unavailable, contact `support@chengjinfang.com`
with:

- the affected version or commit;
- a concise reproduction;
- the expected and observed security boundary;
- whether any credential or personal data may have been exposed.

Do not include live credentials, private repository content, or personal data
in screenshots and logs. Use synthetic examples and redact local home paths.

## Supported versions

Security fixes target the latest revision of `main`. Older snapshots and
locally modified builds are not maintained as separate security branches.

## Disclosure

Please allow reasonable time to investigate and prepare a fix before public
disclosure. Acknowledgement and disclosure timing will be coordinated through
the private report.
